# Figma：把配方变成可编辑图层

[English](README.md)

工作台导出“Figma 交接”JSON。在 Figma 的开发插件流程中新建带界面的插件，保留 Figma 真正分配的 ID。用本目录的 `manifest.template.json` 设置其他字段，加入真实 ID 后保存为 `manifest.json`，与 `code.js`、`ui.html` 放在一起，再通过桌面开发插件入口导入。

打开可编辑的 Design 文件，运行插件，选中 `.figma.json`。它会生成可编辑文字和基本形状，不是整页截图；也不冒充自动布局组件库或双向同步设计系统。

新页面放在既有内容右边，失败时只清理本次创建的页面。字体缺失会回退并给出警告。逐页检查正常字号、换行、边界与层级。

目前有源码与模拟运行测试，真实 Figma 验收仍待完成。本次不会改写你的已有云端文件、发布组件库或调整账户权限。详细步骤和官方文档见[英文说明](README.md)。
