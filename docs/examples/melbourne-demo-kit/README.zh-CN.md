# 墨尔本参赛展示材料

[English](README.md)

原创澳洲英文模板与 DeckWeft 示例，按你确认的 3 分钟制作：8 页主讲，3 页可选问答。借鉴 MLAI 官网的奶油白、橙色、薄荷绿与大字号，不复制其商标、袋鼠、第三方素材或专有模板。

先读[中文演讲指南](presenter-guide.zh-CN.md)，其中有逐页时间、技术比喻、演示步骤、故障回退及问答。你提供了 Dot 主题水壶奖品信息，公开活动页没有给出其评奖规则。

构建命令见英文 README。输出位于 `dist/melbourne-demo-kit-final/output`，包括可编辑 PPTX、离线 HTML、Studio 可导入 JSON、真实核心导出文件、澳洲英文讲稿和中英分开的指南。重建时使用新的输出目录，避免覆盖已有文件。

这是独立编排的展示材料，不是 Studio 新增主题功能。JSON 使用现有主题和四类布局，导入后外观会不同。主讲 PPTX 中的文字和技术架构图可编辑，实际界面截图保持图片。构建不会上传项目、启用付费模型或发布内容。

交付前需要检查每页渲染，并在实际上台使用的应用里检查字体和投影效果。模板不能保证获奖。
