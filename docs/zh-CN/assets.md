# 素材方向、原始来源与受保护裁切

[English](../en/assets.md) · [Visual Studio](visual-studio.md) · [VIS-007 证据](../evidence/vis-007/review.md)

## 打开本地样例

1. 使用 Node.js 22 或更新版本，运行 `npm run studio:assets`。
2. 打开输出的地址（以 `?scene=violet` 结尾）。独立库位于 `dist/visual-assets/library`，与日常文稿库分开。
3. 选择中英文样例，打开“设计 → 素材方向与主体保护”。应看到明确标为非纪实的原创合成验证素材。
4. 点“查看原图与裁切候选”。橙框是作者标记的保护区，圆点是焦点；不会自动识别主体。
5. 比较竖版、方形和宽幅，应用通过的裁切，检查主预览后保存。需要保留全部原图像素时，点“在 16:9 中完整展示原图”。
6. 在终端按 `Ctrl+C` 停止本地服务。

## 描述具名图片槽

1. 选择图片绑定。一页可以有多个具名图片槽。
2. 输入唯一槽名，选择照片、产品截图、插图／概念图或背景。
3. 设置可见原图的最低像素宽高。这是原始分辨率要求，不会执行放大或重采样。
4. 用归一化坐标标记焦点及保护矩形。EXIF 旋转图片的坐标相对已正确转正的保真图。把重要文字、人脸或物体全部包在保护区内；保护区之外的内容可能被裁切。
5. 选择展示方式并点“应用素材方向”。如果当前裁切排除了新保护区，操作会失败；请明确选择完整展示，应用后再查看裁切候选。
6. 对事实性照片／截图，导入时声明原始素材，选择文稿来源引用，再勾选“事实性来源证据”。生成或未分类素材不能满足此用途。素材性质是作者声明，不是系统独立验证照片或截图真实。

旧图片首次成为具名槽时，保留现有裁切，并以其可见范围作为初始保护区；请主动检查并标记实际主体。内容锁定也保护该图片的裁切和槽决定；场景裁切／图片槽锁定会阻止方向编辑和替换。修改前请明确解锁。主题和构图锁定保留原有作用范围。

## 导入 PNG、JPEG 或静态 WebP 原件

1. 选择页面或图片槽，点“导入 PNG／JPEG／WebP 原件”。
2. 选择不超过 1.3 MB 的文件，填写素材性质、来源、许可、允许用途、替代文字和后备描述。生成概念图必须继续标为生成素材。
3. 可明确选择本地有损 JPEG／WebP 网页派生图，默认使用 PNG 精度。浏览器只在当前电脑解码和转换，保留转正后的完整尺寸；测得像素差异过大时拒绝派生图。JPEG 会去除透明度时也会拒绝。
4. 点“保留原件并绑定当前槽”。构图类别、主题、图注、数据集、来源、其他作者选择及其他页面应保留。无图片页面只新增具名槽，不自动更换构图。替换共享图片时，为当前页创建独立绑定。
5. 检查新主体，主动更新保护区，保存并刷新，确认槽和素材记录仍在。
6. 点“下载未修改的原件”。下载字节与原文件一致，原有元数据也保留；下载使用通用文件名，以记录的 SHA-256 哈希识别内容。

原件及每份编码上传须符合 1.3 MB 请求限制。保真 PNG 保留转正后的完整尺寸，也须符合此限制，不会为通过限制而偷偷缩小。超过限制时，请明确选择较小的源图；已经上传的原件仍留在本地，失败不会提交项目绑定。未采用具名槽的旧场景仍可使用“使用本地 PNG”。

服务器检查容器、尺寸、方向和哈希；保真像素转换由浏览器完成，并非服务器独立解码认证。JPEG／WebP 原字节不可变地留在 `visual/asset-originals/`，面向原生目标的保真 PNG 留在 `visual/assets/`。有损网页派生图记录原始来源哈希、方法和尺寸。产品截图及事实性图片使用保真 PNG，其他槽可使用较小派生图。原件、保真图或派生图缺失／哈希改变会阻止使用，不会远程回退。重复导入复用相同文件和哈希；来源／许可记录冲突会报错，不会静默改写署名。

## 从已有文稿提取图片

1. 点“查找本地已保存文稿中的图片”。
2. 选择当前库内已保存 v2／v3 项目的已注册图片。本功能不解析任意 PPTX／PDF，也不读取远程链接。
3. 点“提取并绑定，保留来源文稿”。
4. 检查目标页面。原始来源文稿及文件应不变；目标选择记录来源项目 id、修订、项目哈希与素材 id。来源、许可、允许用途及原件／派生链完整复制。
5. 文件缺失、哈希改变或许可冲突时，请恢复匹配文件，或明确解决冲突。不要把生成图片改标为历史证据。

“复用文稿已有素材”复用当前记录，不生成图片。图片生成后端不可用时，界面明确说明。“选择文字主导的替代构图”是作者主动选择，保留全部现有语义内容及锁定。这些控件不会生成图片、自动重试、收费、读取 API 密钥或调用外部提供方。原有 v2 的主动授权宿主任务日志仍是独立流程。

## 保存和恢复

保存继续检查修订。另一个窗口先保存时，保留当前编辑或导出 JSON，再审阅较新修订。“历史 → 恢复为新副本”保留旧素材／槽记录，不覆盖当前项目。内容寻址图片继续留存以支持恢复；本批不新增自动清理或保留期限策略。

`npm run verify` 覆盖严格合同、裁切、格式、来源复制、哈希、锁定及历史测试。可选的 `tests/browser_assets.mjs` 使用 `/Applications` 之外的隔离测试浏览器和外部 Playwright 验证工具，不是运行依赖。[实际结果、截图与限制](../evidence/vis-007/review.md)。
