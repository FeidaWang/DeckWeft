# 语义交互与确定性回放

[English](../en/interactions.md) · [组件说明](components.md) · [证据](../evidence/vis-009/review.md)

## 应用到已有作品

1. 在 Visual Studio 打开已保存的作品，选择页面，进入“编辑本页 → 内容 → 页面交互与动效 → 为当前页添加讲解交互”。已有图表获得选择控件，已有流程获得分步说明，不创建新文稿或页面；已有交互保持不变。内容已锁定时，需先明确解锁。
2. 没有类别身份的图表会在此次明确操作中创建并保存稳定身份，数值、顺序与单位保持不变。使用“全部系列”、单个系列按钮、复选框和类别范围切换实际图表；图例、当前数据表、范围说明及末项数值共用同一选择状态，完整原始数据仍可查看。
3. 直接编辑步骤标题与说明。所有连线都有身份时，新步骤绑定已有连线，否则绑定已有节点；初始文本仅使用已有标题与注释。选择连线时，连线、两端节点与说明同时更新。可在字段中补充更完整的作者讲解。
4. 本页切换动效可选择“轻微”“关闭”或“跟随主题”。全局动效关闭和系统／用户“减少动态效果”优先；图表、步骤、重播与“下一提示”使用相同状态逻辑和有限动效。
5. 在预览中选择图表或步骤，再点击“将当前图表／步骤设为开场”。保存，等待测量通过后导出 HTML。重新打开及离线 HTML 均从该作者状态开始；观众临时探索不写回作品。开场操作不改图片比较、热点或作者提示顺序。
6. 预览拒绝计划或无法导出时，先修复未应用的 JSON 与排版错误。撤销可恢复先前作者状态，项目 JSON 可保留备份。工作台作品仍须完成原有图片审阅后才可导出；v3 原生 PowerPoint／Figma／AE 导出仍不可用。

下方可选交互样例使用相同编辑器与运行时。

1. 使用 Node 22 或更新版本运行 `npm run studio:interactions`，打开终端打印的本机 `/visual` 地址，在文稿库中选择中英文故事。其他库可点击“交互样例”。每份 15 页故事保留原有四页内容及精确组件示例。
2. 选择图表页，修改“起始类别”“结束类别”和系列复选框。图形、标签、图例与当前数据表同步变化。“完整原始数据（不受筛选影响）”保留原顺序、数值、null、单位和时间点。不允许取消最后一个系列或倒置类别范围，失败时保留先前有效选择。
3. 选择图片比较页，切换“第一张”“第二张”或“并列比较”。实际图片、作者裁切和替代文字随之切换。左右方向键及 Home／End 可选择标签。示例比较同一本地插画的两种作者裁切，不声称代表历史前后变化。
4. 在图片叙事页激活编号热点，查看绑定的原文注释和原图坐标。再次激活可收起说明。页面中始终保留全部原始注释。
5. 在图解／代码页选择说明步骤。图解显示给定节点或定向关系及作者说明；代码在独立摘录中显示指定原文行和行号，上方完整代码、空白、强调与来源锚点不变。左右方向键及 Home／End 也可在步骤按钮间移动。
6. 点击“重播提示序列”，从作者初始状态按顺序播放，每秒一个提示。“暂停提示”停在当前边界；“下一提示”或位置滑块按作者初始状态重新计算确定的提示前缀。滑块支持键盘方向键及 Home／End。手动探索只改变临时视图，不影响重播／定位结果。
7. “减少动态效果”取消视觉动画，保留控件、说明和提示播放。页面不能覆盖操作系统的减少动态效果偏好；作者全局动效“关闭”也优先于单页轻微动效。切换页面或浏览器标签页会停止该页的提示计时器与有限动画，并保留当前信息状态。返回后可重播或继续到下一提示。

鼠标、键盘和触控共用语义动作，控件使用原生焦点行为，触控目标至少 44px。无 JavaScript 时可阅读完整图形、数据、代码、两张来源图片，以及可展开的全部作者说明和提示顺序。声明了静态状态的页面改为显示冻结的图表选择，并附显示值说明行与完整表格。阅读模式允许大图表、图解和代码在组件内部横向滚动。打印请求显示静态内容，不显示播放控件。真实屏幕阅读器、输入法及更广的打印／应用验收仍为独立关卡。

## 冻结静态状态

静态状态是一个关键状态：无 JavaScript 的导出文件显示它，播放器从它开始，减少动态时回退到它。[证据](../evidence/s2-vertical-sample/review.md) · [已知冲突](../plans/design-handoff-vertical-sample.md#conflict-list)。

1. 关键状态来自项目 JSON（场景上的 `keyStates`：`id`、提示 `position` 和可选 `label`；0 即作者设定的开场）。Studio 暂不能新建关键状态；请通过“导入与样例 → 导入视觉 JSON”导入带关键状态的项目。
2. 打开页面，进入“编辑本页 → 内容 → 页面交互与动效”。在“将当前图表／步骤设为开场”旁，把“导出与减少动态时的静态状态”设为某个关键状态，例如 `1 · 先搭结构的习惯（6 种中的 3 种）`。预期：预览显示该选择，提示位置为 `1 / 2`，图表上方一行以“静态视图”开头并列出每个显示值。
3. 保存，等待“✓ 已在当前浏览器测量字体、图片与 DOM 排版”，再点“导出 HTML”。预期：导出文件在阅读视图和演示视图中都从静态状态开始；无 JavaScript 时绘制冻结的选择、数值说明行，以及含完整表格的“查看完整数据”。S4 起数值说明行还会写明筛选条件（“筛选：按作者顺序 A → B（N 个类别中的 n 个）”）；按数值排序的图还会写明排序方式和所示类别在全部类别中的名次，避免把不相邻的名次误读为前 n 名；两种视图以相同尺寸绘制图表。
4. “重播提示序列”仍从作者设定的开场开始，依次播放全部提示。自行探索时数值说明行隐藏，回到静态状态后重新显示。
5. 如需减少动态时回退到静态状态，在“作者交互、提示顺序与动效 · JSON”的场景 `motion` 中设置 `"reducedMotion": "static"`。预期：系统设置或“减少动态效果”开启时，页面显示静态状态，“重播提示序列”不可用，并提示不自动播放。“下一提示”和滑块仍可用。保持 `"instant"`（默认）时，提示照常播放，只去掉动画。
6. “锁定本页交互计划”同时保护静态状态：控件不可用，改变静态状态的保存会被拒绝。请先取消锁定。
7. 恢复：选择“作者设定的开场（默认）”可删除静态状态；`reducedMotion` 为 `static` 时会被拒绝，请先改为 `instant`。若导出返回 `STATIC_STATE_UNIMPLEMENTED`，说明所选关键状态改变了步骤、比较或热点，静态输出暂不能绘制；请选择只改变图表选择的关键状态，或开场。撤销可恢复之前的选择。

## 编辑并保存行为

1. 在“内容”中展开“页面交互与动效”，编辑封闭的 JSON 对象：`interactions`、有序 `cues` 和可选 `motion`。标签、原文说明和来源引用在独立的“语义说明内容”字段编辑；页面计划只保存稳定说明身份，不复制这些事实。保留稳定身份。预览验证失败时保留项目编辑；无效 JSON 作为未应用草稿保留，直至修复或明确放弃。
2. 等待测量通过后保存。项目保存作者配置，观众筛选、标签、热点和步骤不会写回数据或历史。测量会暂时检查作者初始状态，再恢复探索视图；不能通过筛掉内容，让较小的观众视图替代原始来源回执。
3. “锁定本页交互计划”保护 `interactions`、`cues` 与 `motion`，与主题／构图锁定相互独立。内容锁定也保护相关交互定义和提示，包括比较对象和热点注释。观众仍可探索，因其不编辑作者内容。
4. 保存冲突时保留项目 JSON 备份，再打开当前修订。“历史”只读展示快照，恢复会创建独立副本。重排页面或选择构图候选保留页面、内容块、对象、系列和步骤身份。v1／v2 继续原有路径，迁移仍创建明确的副本。

## 契约与边界

页面交互类型为 `chart-select`、`image-compare`、`image-hotspots` 和 `steps`，均绑定同页已有内容块。图表选择必须明确提供 `categoryIds`，不能根据名称或数组位置推断身份。隐藏其他系列后，保留系列仍使用原来的颜色身份。单类别范围仍是真实数值或缺失，不会补出相邻点。重排／删除类别可能令已保存范围或提示失效，须明确修复，不会自动猜测替代对象。

图片比较使用两个已有图片块及其本地素材／裁切，不替换原件。热点用稳定 `id`、归一化原图 `x`／`y`，以及同页已有 `annotationId`。裁切外热点验证失败；完整展示槽会计入留白。更改裁切或来源时仍按这些坐标校验。边缘触控按钮可内移，以保证完整可点；显示的原图坐标保持精确。

步骤包含稳定 `id`、语义 `explanationId`，以及图解给定的 `objectId` 或代码原文 `lines`。代码行引用是作者指定行号，插入或重排代码行后须明确同步修改。全部代码始终转义为文本，不会执行。

事件词汇包括 `scene.enter`、`scene.exit`、`step.next`、`tab.select`、`data.filter` 和 `annotation.reveal`。入场／离场属于生命周期事件，作者提示数组只容纳有界的数据、步骤、标签和注释动作。重播／定位使用纯状态转换器，支持的是提示边界序列，不是视频逐帧编辑器。动效仅为有限的轻微淡入／位移（0～400ms），不会自行自动播放。可选资源释放接口不代表已验证原生 3D／媒体宿主；v3 本身不分配 WebGL 渲染器或外部媒体流。

HTML 在哈希 CSP 下内嵌固定运行时及转义的惰性交互数据，不请求运行包、远程服务、图片提供方或遥测端点。项目 JSON 保留可编辑内容和作者交互计划；独立 Presentation JSON 只包含语义内容。v3 原生 PowerPoint／Figma／AE 编译器仍明确不支持，不以整页栅格化冒充可编辑输出。
