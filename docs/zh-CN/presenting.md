# 使用私密讲稿演示

[English](../en/presenting.md) · [使用手册](manual.md) · [构建证据](../evidence/mb-01-05/review.md)

## 打开讲者与观众界面

1. 在 Studio 中打开文稿，把完整解释写入**内容 → 讲者备注**，幻灯片保留简洁论点。
2. 等待“浏览器已实测 · 可以导出”，点击**演示**。
3. 预期：私密讲者界面显示当前页、下一页和讲稿，同时打开独立观众弹窗。使用标签页的宿主可能将其打开为独立标签页。
4. 共享时只选择观众窗口/标签页，或把它移动到扩展屏幕。镜像屏幕或共享整个桌面可能暴露讲者界面，网页无法替你隐藏其他窗口。

弹窗被阻止或关闭时，点击**打开观众窗口**。刷新观众窗口会使用该标签页本地保存的只读能力重新连接。退出讲者界面后，观众在下一次轮询时清空画面。服务重启后需要重新开始演示并取得新链接。多次崩溃遗留的会话达到四个上限时，停止并重启本地 Studio，可清除内存会话而不影响已保存的项目。

观众服务使用另一个仅限本机的端口，没有编辑器 session 或项目读取接口。它只接收派生 SVG、标题、语言、页码和有效动效偏好，不接收讲稿、私密来源说明、brief、完整项目 JSON 或编辑器凭据。原项目和讲稿留在私密编辑器来源。这不防御已经以你的用户身份运行的恶意进程。

## 阅读与排练

1. 点击**开始提词**。预期：高亮和跟随滚动按估算语速前进。只有你选择下一页时才翻幻灯片。
2. **暂停提词**停止提词时钟，**继续提词**恢复，**重置本页提词**只重置当前页的阅读位置。
3. 手动滚动或在讲稿内按 Page Up/Down，会暂停自动跟随；点击**继续跟随**恢复。查看前文时，独立的演讲计时可以继续。
4. 打开**阅读设置**，分别调整英文词/分钟、中文字符/分钟和句子/段落停顿。混排分别使用两种速度，讲述时间不受原有 2–60 秒动画字段限制。
5. 调整字号、侧栏宽度或左右停靠。可拖动分隔条，也可让它获得焦点后按左右键；重新换行时保留当前文本锚点。
6. 点击**用本页校准语速**，读完完整讲稿，在至少十秒后点完成。预期：根据计时朗读得到受范围限制的语速估算，不使用麦克风或语音识别。

输入框外可使用上一页/下一页、方向键、Page Up/Down、Home/End 和 Escape。讲稿及阅读输入框内，方向键保持正常滚动或编辑职责。相同内容指纹的阅读位置与设置保存在本机；文稿内容变化后，旧位置失效。演示使用启动时的快照，需要展示编辑结果时，先返回编辑，再重新开始演示。

减弱动效时，使用手动滚动和按时间高亮，不强制启动连续跟随。演示前测量凭据过期时，Studio 会请求重新测量；等待就绪后再点演示。

## 设置外观与动效

1. 点击工具栏或讲者界面中的**设置**。
2. 选择**跟随系统**、**浅色**或**深色**。预期：工作区和讲者控件换肤，幻灯片配色保持作者设定。跟随系统会响应操作系统外观变化。
3. 快捷**减弱动态效果**统一控制观看偏好；高级选项提供跟随系统、完整动态、减弱动态和关闭动画。即使选了完整动态，仍尊重操作系统的减弱要求。
4. 预期：CSS/Web Animations、本地 Three.js、视差/重播和提词跟随遵守同一策略。关闭动画会取消正在运行的动画/循环，保留可用的静态内容；不会改写文稿自身的动效设计。

设置保存在本机并同步到其他编辑器标签页，不写入项目 JSON。键盘、对比度、读屏与明确的标签是独立要求，开关不能证明已通过全部无障碍验收。

## 区分观众版与讲者版导出

视觉导出默认不含私密备注和来源说明。确实需要讲者副本时，再勾选**包含私密讲者备注和来源说明**，适用于支持备注的格式。**项目 JSON 始终包含完整私密项目**，包括备注和保留的扩展数据；它是备份，不是观众包。这个开关不会为 Figma 增加讲者备注能力。

命令行使用同样默认值。需要私密副本时显式指定：

```bash
node bin/deckweft.mjs export my.deck.json --format pptx --include-notes --out presenter.pptx
```

`npm run demo` 会在 `dist/presenter-demo/` 生成中英文排练示例，分别包含观众版/讲者版 HTML 和 PPTX。这些是人工编写的产品示例，不是外部研究或真实宿主 AI 输出。

## 开发期类型试点

运行时仍可用 Node 22+ 直接启动，无需安装依赖。开发检查先执行 `npm ci`，再执行 `npm run verify`。唯一开发依赖为固定的 TypeScript 5.9.3（Apache-2.0）：下载压缩包实测 4,377,468 字节，解包 23,625,066 字节；不会进入运行包或插件，运行依赖增量为零。

`npm run types` 从未改变的 schema 生成 Project 声明，检查语速、偏好、计时和浏览器操作注册表，拒绝七个无效契约示例，将 JavaScript、声明与映射输出到 `dist/runtime`，并实际运行编译产物。早期本机检查约 0.4–0.7 秒，当前数据见 `dist/types/verification.json`。这是限定范围的类型/构建试点，不能理解为整个服务、UI 和导出器已经迁移到 TypeScript。JavaScript 启动入口及复制出的插件继续支持离线运行，试点构建清单位于 `dist/runtime/build-manifest.json`。
