# Visual Studio

[English](../en/visual-studio.md) · [构建检查](../evidence/visual-studio/review.md) · [早期 Wave A](visual-first.md)

Visual Studio 是同一本地 DeckWeft 应用中的 v3 编辑工作区。点击经典 Studio 文稿库下方的 **Visual Studio · v3**，或打开本地地址的 `/visual`。已有 v1/v2 文稿仍留在经典工作区；迁移会显式建立独立副本。

## 现有作品的视觉表达

共享渲染器为现有 v3 项目提供按内容区分的字体层级：开场突出大标题，证据与比较页为数据留出空间。奶油拼贴结合衬线标题、暖纸色、蓝色数值与铁锈红强调；电紫叙事结合粗体无衬线标题、安静的图文页和作者指定的整页紫色章节；黑底数据使用深绿色背景、浅色文字和可区分的图表颜色。全部使用系统字体后备，不加载字体文件或远程资源。

1. 在 `/visual` 打开已有作品，查看开场、内容页和结尾。应能看到不同标题档位、受控的正文阅读宽度，以及围绕重点安排的留白。
2. 在“编辑本页 → 设计”调整字号对比与密度。均衡对比降低展示字号档位；紧凑密度减少间距，保留文字与数据。
3. 比较图文构图。竖幅图片在原有比例与裁切内缩放，不通过拉伸或重新裁切强行适配。
4. 在“探索构图与整篇节奏”比较三种构图。检查候选后再应用已测量的整稿节奏。选择器兼顾开场、证据、收尾与相邻重复，并排除失败候选。
5. 切换到“阅读 · 390”。中文使用独立阅读字号档位，避免标题过度碎行；原文换行仍保留。
6. 重新检查并导出当前作品。预览、缩略图和观众 HTML 使用同一套派生字体、留白与配色。渲染器变化使旧审阅依据失效；之前通过的成品仅作为明确标识的历史版本保留。

稀疏页面使用更开放的空间；密集页面保留所有内容块，可以增长或超过演示预算。来源引用仍可见。渲染规则不改写原文、数值、主题身份、裁切或作者锁定。视觉改善不代表事实已被验证。

## 打开样例

1. 在源码根目录使用 Node.js 22 或更新版本，执行 `npm run studio:visual-demo`。
2. 打开终端打印的 Visual Studio 地址。此命令使用 `dist/visual-studio/library` 内的隔离样例库。
3. 选择英文或中文样例。每份有四页：Cream Collage 封面、Dark Data 数据页、Electric Violet 图文页与紫色章节页。
4. 选择第三页。在“设计”里查看主题、作者偏好和裁切；在“内容”里编辑文字。
5. 点击“保存”并刷新，修改、主题、裁切和偏好应仍然存在。
6. 实测预览就绪后点击“导出 HTML”。独立打开文件，可使用阅读／演示导航；运行代码与本地 PNG 已内嵌。
7. 在终端按 `Ctrl+C` 停止本地服务。

使用日常文稿库时，执行 `node bin/deckweft.mjs studio --open` 后进入 Visual Studio。空库提供“新建视觉样例”与“迁移已有文稿”。样例数据均为合成数据，工作桌图片是原有生成装饰插画，不是纪实摄影或产品证据。创建样例不会调用模型、图片工具或远程服务。

## 分别编辑内容与设计

在左侧选择页面。“内容”可编辑文字、列表、数值、图表数据、图片替代文字与其他类型化内容块。图表值必须是 JSON 数字，修改后曲线和完整数值表同时更新。来源引用与版本快照锚点提供高级 JSON 编辑器。保留来源不等于验证了事实。

“设计”只改变当前页。Cream Collage 使用衬线大标题与斜切色块；Dark Data 使用黑底、图表和说明栏；Electric Violet 使用大图分栏或整页紫色章节。切换主题会选择兼容构图，保留事实、说明、素材引用和其他页面。

作者偏好保存色彩强度、字号对比、密度、动效与图像比重。“受众”和“输出语言／字体偏好”属于文稿，“界面语言”属于本地工作区。语言选择不会翻译已有文字。动效默认关闭，并尊重系统减少动态效果的设置。

可锁定内容块，或锁定当前页主题与构图。锁定图表也保护关联数值和来源记录。需要修改时先显式解锁；保存、刷新和换主题都会保留锁定，冲突不会被静默忽略。

“撤销／重做”处理本地编辑。无效 JSON 会在切换页面时保留，并阻止保存及 HTML 导出。修复后继续，或点击“放弃未应用的字段修改”保留上次有效内容。包含未应用字段的项目 JSON 是明确的恢复草稿，需先修复，才能作为正常项目导入。

## 使用图片

1. 选择页面，在“设计”中点击“使用本地 PNG”。
2. 选择小于 1.3 MB 的 PNG，填写来源、许可、允许用途、替代文字和后备说明。
3. 附加图片。有图片时原位替换，保留构图、裁切、数据集和其他作者选择。
4. 用归一化 `x`、`y`、`width`、`height` 裁切。保证 `x + width ≤ 1`、`y + height ≤ 1`。超出边界会报错，不自动修补。
5. 保存并检查实测预览，再导出。

PNG 按内容哈希存储并校验。源字节不变，裁切使用语义图片标记，不把整页变成截图。内置约 2.4 MiB 插画由包直接载入；浏览器导入仍使用上述较小限制。资源预算会计算同一图片在多个场景中的重复使用。

资源缺失或哈希变化会阻止导出。可恢复匹配文件，或显式附加替代图片。[VIS-007 素材流程](assets.md)现支持保留 JPEG／WebP 原件、本地派生图、作者标记保护区的裁切及来源文稿复用；自动主体识别和 v3 图片生成传输仍不可用。

## 保存与恢复

v3 文稿位于 `<文稿库>/visual/projects/`，图片位于 `<文稿库>/visual/assets/`。v1/v2 路径不变。两种文稿库共用原子写入、修订冲突检查、不可覆盖历史快照与恢复为副本的实现。

另一个窗口先保存时，当前编辑仍留在窗口中。可先导出项目 JSON 备份，再打开较新版本或导入为副本。保存期间继续编辑时，只保存本次快照，后续修改仍标为未保存。

打开“历史”，查看只读快照，再点击“恢复为新副本”。当前项目不变，相同恢复请求重试会复用副本。

“迁移已有文稿”读取选中的已保存 v1/v2 文稿，归档完整原始 JSON 与哈希。旧数字字符串仍是文字；素材、意图、私密备注等保留在归档里，并说明迁移限制，不猜测数字，也不承诺视觉一致。

项目 JSON 包含完整私密记录、设计计划、素材清单、修订与归档，但图片仍引用本地文件。转移到另一文稿库时需保留 assets 文件夹。导入会先验证原始记录，再建立新的副本身份。HTML 内嵌图片，便于转移，但不包含迁移归档和私密备注。以隔离截图浏览器启动 Studio 时，导出组中提供 PowerPoint 与 PDF（见[作者控制](#作者控制章节与分项锁定s9a)）。v3 的 Figma/AE/SVG 尚不支持，会明确报错；经典 Studio 原有导出和讲者功能保持原有路径。

## 比较构图与选择整稿节奏（VIS-006）

1. 运行 `npm run studio:compositions`，打开输出的 `/visual` 地址。独立示例库位于 `dist/visual-compositions/library`，首次创建中英文六页样例。在其他视觉库中，可点“新建六类构图样例”。
2. 选择页面，打开“设计”，选择构图类别。缺少所需图片、数值、图表、表格或流程图时，对应类别不可选。每类提供三种不同结构，保留全部现有内容块。
3. 在主预览下方点“比较三种构图”。等待三个实际预览和测量结果。浏览器在字体、图片就绪后，以 1440px 宽度测量所有页面。点“放大查看”检查候选，再关闭查看窗口。
4. 在通过的候选上点“使用此构图”，或点“应用已测量的整稿节奏”。整稿选择兼顾开场、页面角色和收尾的叙事适配，以及实际焦点位置、内容占用面积、图片面积、色彩模式与相邻构图重复，沿当前页序选择。主题、色彩模式、焦点绑定、裁切、事实、引用、素材与作者锁定均保留。综合节奏成本是排版启发式指标，不代表内容质量或真实性。应用整稿节奏时，项目扩展字段保存带依据哈希的决策记录。
5. 检查更新后的预览与节奏说明，点“保存”，刷新后确认构图仍在。“撤销”、修订冲突检查及“历史 → 恢复为新副本”继续可用。
6. 使用“上移／下移”重排页面。主题跟随稳定页面身份。重排或编辑后重新比较，旧测量不能用于已改变的内容。

内容溢出、被裁切、测得对比度不足、字体未就绪，或在 1440px 宽度下超出 900px 演示候选高度预算，均会使候选失败。失败候选保留全部内容并显示原因。全部失败时停止选择：保留原文并修复排版，或由作者明确拆分成更多页面。阅读模式可纵向增长，高度预算只用于演示候选。测量十分钟后过期，可重新比较；保存后也需按新修订重新比较。

六类分别为：观点陈述（左右分栏／顶部横幅／居中）、图像叙事（左图／顺序图文／右图）、超大数值（左置／横向数值带／右置）、数据证据（左图表／通栏／右图表）、比较（矩阵／侧栏／维度卡）、流程（横向／纵向／阶梯）。已覆盖 Cream Collage、Electric Violet、Dark Data 及中英文代表内容。[测量几何、截图、失败与修复记录](../evidence/vis-006/review.md)。

## 新增六类构图（S3）

S3 在上述六类之外再增加六类，每页可选的构图类别共十二类。新增类别不会根据内容自动推断，需要由作者主动选择。

1. 选择页面，打开“设计 → 构图类别”。新类别排在原有六类之后：章节、前后对比、系统关系图、小倍数图、引语、结论与下一步。页面缺少所需内容块时，对应类别不可选。
2. 点“比较三种构图”，等待三个已测量的预览。页面不符合该类别的内容约定时，比较会停止并显示原因（提示为英文，例如 *Attribute every verbatim quotation*：请为每段原话标注出处）。系统不会替你修补或删除任何内容。
3. 选择一个通过的候选，或点“应用已测量的整稿节奏”。你选的类别保持不变，整稿节奏只在该类别的三种结构中选择。
4. 保存并刷新，构图保持不变。

| 类别 | 需要 | 三种结构（阅读路径） | 1440 / 1024 / 390px |
|---|---|---|---|
| 章节 | 标题；只含文字（不含图表、表格、流程图、图片、数值、代码） | 左下标题、旁侧导语 · 左侧标题与导语、右侧目录 · 窄边栏目录、右侧标题 | 2 / 2 / 1 |
| 前后对比 | 恰好两张图片，同为事实照片或同为插图，以相同宽高比显示 | 左基线、右变化后 · 文字栏加上下两图 · 基线、变化说明、变化后 | 2 / 2 / 1（三联 3 / 3 / 1） |
| 系统关系图 | 有分支或回路的关系图（单一链条属于流程） | 标题行、通栏关系图、图例行 · 左图右文 · 左图例、右关系图 | 2 / 2 / 1；侧栏与图例两种在 1024 纵排 |
| 小倍数图 | 两个及以上图表，图表类型、单位、固定数值轴（相同范围与刻度）一致；折线、面积、堆叠与热力图还需相同类别 | 面板并列、说明在下 · 标题旁为读图说明、面板在下 · 居中标题、说明与要点分列中轴两侧 | 2 / 1 / 1 |
| 引语 | 引语块，且每段引语都由引用其来源之一的出处块标注 | 居中原话 · 左转述、右原话 · 通栏原话带 | 1 / 1 / 1（居中），2 / 2 / 1 |
| 结论与下一步 | 下一步列表 | 左结论、右步骤 · 步骤排成一行 · 居中结论与请求 | 2 / 2 / 1 |

各项约定保护什么：

- **前后对比。** 内容块顺序中的第一张图片是基线。每种结构都把它放在前面（左侧、上方或第一列），并在图片上方标出“之前 · 基线”和“之后”。无需交互即可看到标签，无 JavaScript 视图和打印中同样可见。两个画框尺寸相同。两张图以不同宽高比显示时无法保存：请把两张图裁切成相同取景。页面上的对比控件必须把基线与变化后的图片配对，且不能只显示变化后的图片作为开场。
- **小倍数图。** 共用尺度由作者声明，不靠推断：每个面板都需要相同范围的固定数值轴。面板始终等大。按当前图表绘制，1440px 一页可放两个面板；1024 与 390px 时纵向排列。面板更多时，调用 `src/design/rhythm.mjs` 中的 `splitSmallMultiples(project, sceneId, perPage)` 拆页。每页保留标题与来源，面板顺序不变，文字块留在第一页。页面含交互或锁定，或某页只剩一个面板时，会拒绝拆分。Studio 暂无对应按钮。
- **引语。** 原话是引语块，以展示字体排出，并带装饰引号。标注它的出处紧接在下方。转述是段落，使用正文字体，用细线分隔，永远不会排成引语样式。说话人与机构写在出处文字中，引语块没有单独的说话人字段。

### 节奏规则

“应用已测量的整稿节奏”现在还遵循交接包中的三条规则，仍未满足的规则会列在按钮下方的报告中：

- 同一构图最多连续两页。同一比较类别（比较、流程、前后对比、小倍数图）可以连续：一组顺序内容可以保持同一结构。
- 不出现连续三页“标题加卡片”（比较的维度卡或排成一行的下一步，且卡片不少于三张）。
- 10–15 页的文稿至少使用四种构图类别。类别来自你的内容和选择，因此这条规则只给建议：报告会列出可改用未使用类别的页面，但不会自行修改。

作者的选择优先。用“锁定当前页主题与构图”锁定的构图即使违反规则也会保留，报告中标为“保留：作者锁定”。没有锁定却仍未满足的规则，表示没有任何已测量的候选可以避免它。

### 切换主题保留色彩模式

现在切换页面主题时，只改变主题，必要时改变构图，色彩模式保持原样。切到其他主题再切回，会得到原来的方案和相同的渲染哈希。只有页面能使用章节色彩时，才会提供紫色章节构图；色彩模式明确设为 *default* 的页面改用流式阅读。

### 出错时怎么办

- *Show both states at the same aspect ratio*（两种状态的宽高比不同）：修改其中一个裁切，使两者一致，再保存。
- *Declare the shared scale*（未声明共用尺度）：为每个图表设置相同的 `axis: {policy: "fixed", min, max}`。
- *No measured candidate fits*（没有通过测量的候选）：保留内容。改用其他类别、自行精简文字，或把小倍数图拆成更多页。

1. 选中一页，打开 **设计 → 当前页主题**，选择三套之一。页面保留所有内容块，并按内容取该主题的自有构图：有图表的页得到 `…-figure`，舞台主题上有数值的页得到 `stage-metric`，纯文字页得到该主题的封面。
2. 像以前一样在 **构图类别** 中选择主题的其他构图。主题专属构图拒绝其他主题，并说明缺少的内容块（例如 *atlas-panels needs at least 2 chart panels*）；不会替你删除任何内容。
3. 像以前一样比较三种构图并应用节奏。节奏只在共用构图族内改变几何；主题专属构图保留到你更换为止。
4. 导出。同一主题包到达 HTML、PowerPoint 和 PDF（`npm run export:targets -- --s8` 运行 S8 文稿）。

配对：一份演示可以用 Editorial Fieldnotes 讲叙事，用 Research Atlas 承载证据章节。两者共享字号档位、引用角色和稳定的图表颜色顺序，因此图例的含义不会随章节漂移。

### 渲染器现在消费的 Token 角色

三套主题包声明了 S1 的 Token 角色，页面以自定义属性接收：`--numeric`（数值、图表读数、坐标刻度、表格数字）、`--reference` 与 `--missing`（参考线、缺失值标签与注释）、`--caption-gap`、`--section-gap`、`--safe-area`，以及 `--motion-distance`、`--motion-easing`、`--motion-delay`。未声明这些角色的主题包（例如 VIS-014 的三套）渲染结果与以前完全相同，因为每个消费处的回退值就是原来的字面值。动作的 `fallback`（`instant` 或 `static`）是页面自身未声明时的低动作结果。

### 中文标题在词之间换行（C12）

在 zh-CN 文档中，标题、提示语和数值标签在词典分词边界处带有 `<wbr>`，并使用 `word-break: keep-all`，因此行尾落在词与词之间（三十六种 · 几何 · 结构），而不是词内。汉字数字与量词保持在一起。`<wbr>` 没有文本内容，复制的文字、覆盖检查和所有导出器看到的仍是作者原文。页面的 `overflow-wrap: anywhere` 仍是比栏宽更长的词的最后手段。分词边界来自平台 ICU 词典（`Intl.Segmenter`）；证据记录了 ICU 版本。

### 缺字形会被检测（C13）

适配审计把页面上每个不同的字符用其计算字体画到画布上，并与同一字体的 `.notdef` 方框（未分配码位 U+0378）比较。相同即为缺字形：适配失败，Studio 门返回 `VISUAL_FIT`，构图候选报告 *Missing glyph*，质量流水线记录 `glyph` 问题，导出就绪阶段以 `FONT_GLYPH_MISSING` 拒绝。请修改文字或主题字体，绝不导出一个方框。DevTools 平台字体探针作为第二信号保留，用于引擎报告末位备用字体的情况。

### 出问题时

- *`atlas-panels` needs at least 2 chart panels* 或 *Declare the shared scale*：给每个面板相同的图表类型、单位、类别和固定坐标轴。
- *`stage-hero` … belongs to the orange-launch theme*：换主题时保留了另一个主题的专属构图；请选择新主题的构图。
- 看起来正常的页面报告 *Missing glyph*：该字符在所选字体族中被画成方框；查看适配报告中的 `glyphs` 列表确认字符和字体。
- 中文标题仍在词内断开：该词在此字号下比栏宽还长，触发了最后手段。缩短栏内文字、换一种构图，或加入作者换行。

原件保留、具名槽和受保护裁切请见[素材说明](assets.md)。运行 `npm run studio:assets` 打开中英文实验样例。

## 作者控制、章节与分项锁定（S9a）

**编辑页面 → 作者控制**以先说明、后应用的方式修改设计。每个控件的用法相同：

1. 选择**作用范围**：当前页、当前章节、整套演示或单个对象（在第二个列表中选择对象）。
2. 点击控件。预期出现计划框，其中有范围说明、逐页列出的每项效果，以及因作者锁定而保留的每一项。此时尚未修改任何内容。
3. 点击**应用**或**取消**。**撤销**可恢复之前的状态，**保存**后保留。如果计划之后文稿已改变，应用会被拒绝，请重新规划。

| 控件 | 做什么 | 绝不做什么 |
|---|---|---|
| 更具编辑感 | 把每页改为所属构图类别的编辑式版式（论点先行、非对称；Editorial Fieldnotes 页面改用其封面、论点、方法、图形或结尾版式），并在所选层级设为强烈字体对比与宽松密度。 | 更换主题或改动任何文字。 |
| 给图表更多空间 | 把单图页面改为该主题中图表绘制最大的版式。Research Atlas 中是 `atlas-figure`，Editorial Fieldnotes 中是 `fieldnotes-figure`，其他主题是侧栏版式，因为通栏的 `evidence-top` 会限制图表高度。若页面已采用该版式，辅助文字会移入页面折叠内容。多于两个面板的页面会按同一尺度拆为每页两个面板。 | 隐藏限定条件：含数值、单位、“合成”“未测量”等词的文字保留在页面上。 |
| 更安静 | 为整套或所选页面关闭动效。提示即时生效，每个关键状态仍可用“下一步/上一步”到达。动效已关闭时显示“已经安静”。 | 删除状态或提示。DeckWeft 输出没有循环或自动播放。 |
| 保留此版式 | 添加构图锁定。共享构图在任何主题更换后保留；主题专属构图（例如 `atlas-figure`）会让主题更换被拒绝并给出名称。节奏报告标为“作者锁定保留”。 | 锁定文字、数据或来源。 |
| 替换视觉 | 用项目中已有的另一张图片替换一张图片，并要求新的替代文字。列出需要检查的裁切与本页引用。 | 改变构图、裁切或其他内容；替换已锁定的图片。 |
| 减少文字 | 把辅助段落和列表移入同一页上关闭的“更多细节”；在对象范围内移入所选的段落、列表或标注。第一项辅助内容保留为本页说明。 | 删除或改写任何内容。论点、要点、数值、单位、限定条件与来源都留在页面上；移走的文字仍在网页、PowerPoint 备注与 PDF 附录中。 |

**四个层级。**偏好按“对象 → 页面 → 章节 → 整套”由具体到一般生效：页面配置优先于章节配置，章节配置优先于整套配置。播放器同样遵循这一顺序：动效关闭的章节或页面不播放动效，整套的“关闭”在任何位置都优先。配置锁定保护页面自身的配置；没有自身配置的锁定页面会随整套与章节的修改变化，计划框会说明。若要保持外观，请先为该页设置页面配置。对象层级承载逐对象的选择：锁定、要替换的图片、要移走的文字。**从此页开始新章节**在当前页开始一个章节，延续到下一个章节起始页之前，并沿用被拆分章节的配置，画面不变。**移除此章节**让其页面回到前一个章节或不属于任何章节。章节随页面顺序变化，移动或拆分页面不会留下空缺。章节起始页在页面列表中带有“章节”标记。

**分项锁定。**选择“文字”“数据”“来源”或“构图”，点击**锁定**或**解锁**：

- 文字：锁定对象的书写内容；
- 数据：锁定数据集（数值、单位、定义、缺失原因、事件与区间）；
- 来源：锁定来源记录；
- 构图：锁定页面版式。

第一次使用数据或来源锁定时会运行显式迁移 `separateLocks()` 并说明。旧（合并模式）文稿中，锁定图表会同时锁定其数据集与来源；迁移会复制这些隐含锁定，不会释放任何锁定。之后图表的文字与数据可以分别锁定。每项锁定在更换主题、保存来源更新以及**历史 → 恢复为新副本**之后都会保留。

**页面折叠内容。**由“减少文字”或“给图表更多空间”移走的文字显示在构图之后，标为“更多细节 · n 项”。读者可在页面上展开，无需 JavaScript。PowerPoint 将其放入幻灯片备注并为每项内容给出回执，PDF 将其放在备注页。构图规则只作用于仍可见的内容，例如结尾页会保留其列表。

**导出组。**“Export HTML”旁边是 **PowerPoint**、**PDF** 和**项目 JSON**。PowerPoint 与 PDF 需要以 `--capture-browser /absolute/isolated/chromium` 启动 Studio；否则按钮不可用，服务器以 `TARGET_BROWSER_REQUIRED` 拒绝。启动后，当前已测量的预览会作为静态场景再测量一次，按导出顺序编译（ready → static-state → freeze → stop-motion → reveal → render → check）；提示列出各阶段、L1/L2/L3 数量和元素回执数量。未通过自身检查的文件会被拒绝（`EXPORT_CHECK_FAILED`），不会下载。工作台文稿只有在当前内容通过图片审阅后才能导出 PowerPoint 或 PDF。标记为待补证据的页面会拒绝所有最终导出。请自行在 PowerPoint、Keynote 或 PDF 阅读器中打开文件：这些导出在本机经过文件包检查，并非应用验证。

### 出问题时

- “计划之后文稿已改变”：重新规划该控件。
- “构图已锁定，保持不变”：如需让控件修改它，请先解锁版式（构图 → 解锁）。
- “已经安静”或“没有可移走的内容”：控件没有发现需要修改之处，计划框会说明原因。
- `EVIDENCE_REQUIRED`：补充证据并将页面设为 sourced，或设为 illustrative。
- `EXPORT_CHECK_FAILED`：提示逐页列出未通过的检查；修改该页后重新导出。
