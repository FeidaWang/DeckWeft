# Visual Studio

[English](../en/visual-studio.md) · [构建检查](../evidence/visual-studio/review.md) · [早期 Wave A](visual-first.md)

Visual Studio 是同一本地 DeckWeft 应用中的 v3 编辑工作区，与经典工作台使用同一个外壳：顶部（撤销、文稿标题、状态方块、**更多**、**带走**）、页面条、页面，以及页面旁上下排列的**词**和**样子**。从**更多 → 备份与还原 → 我的文稿**打开视觉文稿，或打开 Studio 打印的地址：`/visual` 会跳转到那里，并保留查询参数。已有 v1/v2 文稿仍留在经典工作台；迁移会显式建立独立副本。

## 现有作品的视觉表达

共享渲染器为现有 v3 项目提供按内容区分的字体层级：开场突出大标题，证据与比较页为数据留出空间。奶油拼贴结合衬线标题、暖纸色、蓝色数值与铁锈红强调；电紫叙事结合粗体无衬线标题、安静的图文页和作者指定的整页紫色章节；黑底数据使用深绿色背景、浅色文字和可区分的图表颜色。全部使用系统字体后备，不加载字体文件或远程资源。

1. 在 Visual Studio 打开已有作品，查看开场、内容页和结尾。应能看到不同标题档位、受控的正文阅读宽度，以及围绕重点安排的留白。
2. 在**样子**里点**字大一点**（默认已按下：强烈对比；再按一次为均衡对比，降低展示字号档位），或点**多留白**（本页的编辑式版式与宽松密度，减少拥挤）。这些选择立即生效，保留文字与数据，**撤销**可撤回。
3. 比较图文构图。竖幅图片在原有比例与裁切内缩放，不通过拉伸或重新裁切强行适配。
4. 查看**样子**顶部的三个选择；页面测量完成后会自动比较。检查后再点**整份一起选**应用已测量的整稿节奏。选择器兼顾开场、证据、收尾与相邻重复，并排除失败的选择（标为“放不下”）。
5. 切换到“阅读 · 390”。中文使用独立阅读字号档位，避免标题过度碎行；原文换行仍保留。
6. 重新检查并导出当前作品。预览、缩略图和观众 HTML 使用同一套派生字体、留白与配色。渲染器变化使旧审阅依据失效；之前通过的成品仅作为明确标识的历史版本保留。

稀疏页面使用更开放的空间；密集页面保留所有内容块，可以增长或超过演示预算。来源引用仍可见。渲染规则不改写原文、数值、主题身份、裁切或作者锁定。视觉改善不代表事实已被验证。

## 打开样例

1. 在源码根目录使用 Node.js 22 或更新版本，执行 `npm run studio:visual-demo`。
2. 打开终端打印的 Visual Studio 地址。此命令使用 `dist/visual-studio/library` 内的隔离样例库。
3. 选择英文或中文样例。每份有四页：Cream Collage 封面、Dark Data 数据页、Electric Violet 图文页与紫色章节页。
4. 在页面条上选第三页。在**样子**里查看配色和**图片**（**i** 显示权利、位置和裁切）；在**词**里编辑文字。
5. 等顶部状态方块显示“已保存在本机”（最后一次编辑 1.2 秒后自动保存），再刷新。修改、主题、裁切和偏好应仍然存在。
6. 页面测量完成后点**带走 → HTML**。独立打开文件，可使用阅读／演示导航；运行代码与本地 PNG 已内嵌。
7. 在终端按 `Ctrl+C` 停止本地服务。

使用日常文稿库时，执行 `node bin/deckweft.mjs studio --open` 后进入 Visual Studio。空库显示首次使用的粘贴框：粘贴文字后点**排好**，或点**先看个例子**。样例数据均为合成数据，工作桌图片是原有生成装饰插画，不是纪实摄影或产品证据。创建样例不会调用模型、图片工具或远程服务。

## 分别编辑内容与设计

在页面条上选择页面。“词”可编辑文字、列表、数值、图表数据、图片替代文字与其他类型化内容块；文稿标题在顶部。图表值必须是 JSON 数字，修改后曲线和完整数值表同时更新。图表设置和代码元数据在各自卡片内的“设置”折叠里。来源引用与版本快照锚点的高级 JSON 编辑器在**更多 → 给开发者 → 数据编辑**。来源记录只保留出处，不证明论断为真。

**样子**只改变当前页。六种配色是：Cream Collage（衬线大标题与斜切色块）、Dark Data（黑底、图表和说明栏）、Electric Violet（大图分栏或整页紫色章节）以及下面的三套 S8 主题。切换时会选择兼容构图，保留事实、说明、素材引用和其他页面。

作者偏好保存色彩强度、字号对比（**字大一点**）、密度（**多留白**）、动效（**让这页会动**）与图像比重。“受众”在**更多 → 让助手帮我写**；“输出语言”在**更多 → 语言**，界面语言是同一节里的唯一切换键。语言选择不会翻译已有文字。动效默认关闭，并尊重系统的减少动态设置。提示词语言、语气和预览宽度已不存在：草稿发送输出语言和中性语气，舞台会缩放 1440 px 宽的页面。

点**别动这页**保护本页：文字、数据、来源和版式，以及主题、交互、提示和动效。锁定图表也保护关联数值和来源记录。再按一次即放开。保存、刷新和换主题都会保留锁定，冲突不会被静默忽略。锁定状态在**更多 → 给开发者**里以只读方式显示。逐项锁定留给 API（见[样子控件](#样子控件章节与锁定s9a)）。

用顶部的**撤销**／**重做**处理本地编辑（按住撤销半秒会显示重做）。无效 JSON 会在切换页面时保留，状态方块提示需要留意，并阻止保存及 HTML 导出。修复后继续，或点击“放弃未应用的字段修改”保留上次有效内容。包含未应用字段的项目 JSON 是明确的恢复包装；导入为视觉项目前，请先修复这些字段。

## 使用图片

1. 选择页面。在**样子 → 图片**中点 **i**，选择“使用本地 PNG”。（**换一张图**／**加一张图**，或把图片拖到页面上，会打开图片导入对话框。）**i** 里还有权利、位置、裁切、已保存本地文稿中的图片目录，以及不想用图时的以文字为主的版式；这里不生成图片。
2. 选择小于 1.3 MB 的 PNG，填写来源、许可、允许用途、替代文字和后备说明。
3. 附加图片。有图片时原位替换，保留构图、裁切、数据集和其他作者选择。
4. 打开**图片**旁的 **i**，用归一化 `x`、`y`、`width`、`height` 裁切。保证 `x + width ≤ 1`、`y + height ≤ 1`。超出边界会报错，不自动修补。
5. 等状态方块显示已保存，并检查实测预览，再导出。

PNG 按内容哈希存储并校验。源字节不变，裁切使用语义图片标记，不把整页变成截图。内置约 2.4 MiB 插画由包直接载入；浏览器导入仍使用上述较小限制。资源预算会计算同一图片在多个场景中的重复使用。

资源缺失或哈希变化会阻止导出。可恢复匹配文件，或显式附加替代图片。[VIS-007 素材流程](assets.md)现支持保留 JPEG／WebP 原件、本地派生图、作者标记保护区的裁切及来源文稿复用；自动主体识别和 v3 图片生成传输仍不可用。

## 保存与恢复

v3 文稿位于 `<文稿库>/visual/projects/`，图片位于 `<文稿库>/visual/assets/`。v1/v2 路径不变。两种文稿库共用原子写入、修订冲突检查、不可覆盖历史快照与恢复为副本的实现。

文稿在最后一次编辑 1.2 秒后自动保存。顶部的方块显示状态：正在保存、已保存、未保存或需要留意。另一个窗口先保存时，不会覆盖任何内容：当前编辑仍留在窗口中，方块变红并出现横幅。按 ⌘/Ctrl S 可另存为副本，也可先用**项目 JSON**（**更多 → 备份与还原**）留下编辑，再打开较新版本。保存期间继续编辑时，只保存本次快照，后续修改随后保存。保存后会重新测量页面。

打开**更多 → 之前的版本 → 历史版本**，查看只读快照，再点击“恢复为新副本”。当前项目不变，相同恢复请求重试会复用副本。

Visual Studio 不迁移旧的 v1/v2 文稿。要带入已保存的旧文稿，请在经典工作台打开它并点**做一份新版副本**（API 路由 `POST /api/visual/migrate` 作用相同）。归档完整原始 JSON 与哈希。旧数字字符串仍是文字；素材、意图、私密备注等保留在归档里，并说明迁移限制，不猜测数字，也不承诺视觉一致。

项目 JSON 包含完整私密记录、设计计划、素材清单、修订与归档，但图片仍引用本地文件。转移到另一文稿库时需保留 assets 文件夹。导入会先验证原始记录，再建立新的副本身份。HTML 内嵌图片，便于转移，但不包含迁移归档和私密备注。以隔离截图浏览器启动 Studio 时，**带走**中提供 PowerPoint 与 PDF（见[带走](#带走)）；项目 JSON 在**更多 → 备份与还原**。v3 的 Figma/AE/SVG 尚不支持，会明确报错；经典 Studio 原有导出和讲者功能保持原有路径。

## 比较构图与选择整稿节奏（VIS-006）

1. 运行 `npm run studio:compositions`，打开输出的 Visual Studio 地址。独立示例库位于 `dist/visual-compositions/library`，首次创建中英文六页样例。在其他视觉库中，打开**更多 → 给开发者 → 更多例子 → 新建六类构图样例**。
2. 选择页面。要手动选构图类别，打开**更多 → 给开发者 → 构图类别**。缺少所需图片、数值、图表、表格或流程图时，对应类别不可选。每类提供三种不同结构，保留全部现有内容块。
3. 查看**样子**顶部的三个选择：三个实际预览，各带测量结果。浏览器在字体、图片就绪后，以 1440px 宽度测量所有页面，约 0.6 秒后自动比较，每次编辑或保存后再比较一次。点“放大查看”检查其中一个，再关闭查看窗口。
4. 点一个通过的选择即采用，或点**整份一起选**，对所有页面一起选。整稿选择兼顾开场、页面角色和收尾的叙事适配，以及实际焦点位置、内容占用面积、图片面积、色彩模式与相邻构图重复情况；它按当前页面顺序选择构图，保留主题、色彩模式、焦点绑定、裁切、事实、来源、素材和锁定。综合节奏成本只是版式启发值，不是质量或真实性评分。应用节奏时，带依据哈希的决策报告保存在项目扩展中；报告和状态在**更多 → 给开发者**里。
5. 检查更新后的预览。自动保存会保留它：刷新后确认构图仍在。“撤销”、修订冲突检查及**更多 → 之前的版本 → 恢复为新副本**继续可用。
6. 使用**样子**下方的 ↑ / ↓ 按钮重排页面。主题跟随稳定页面身份。编辑或重排后，等三个选择重新测量：旧测量不能用于已改变的内容。

内容溢出、被裁切、测得对比度不足、字体未就绪，或在 1440px 宽度下超出 900px 演示候选高度预算，均会使候选失败。失败候选保留全部内容并显示原因。全部失败时停止选择：保留原文并修复排版，或由作者明确拆分成更多页面。阅读模式可纵向增长，高度预算只用于演示候选。测量十分钟后过期，页面改变后会自动重新比较；保存后也需按新修订重新测量。

六类分别为：观点陈述（左右分栏／顶部横幅／居中）、图像叙事（左图／顺序图文／右图）、超大数值（左置／横向数值带／右置）、数据证据（左图表／通栏／右图表）、比较（矩阵／侧栏／维度卡）、流程（横向／纵向／阶梯）。已覆盖 Cream Collage、Electric Violet、Dark Data 及中英文代表内容。[测量几何、截图、失败与修复记录](../evidence/vis-006/review.md)。

## 新增六类构图（S3）

S3 在上述六类之外再增加六类，每页可选的构图类别共十二类。新增类别不会根据内容自动推断，需要由作者主动选择。

1. 选择页面，打开**更多 → 给开发者 → 构图类别**。新类别排在原有六类之后：章节、前后对比、系统关系图、小倍数图、引语、结论与下一步。页面缺少所需内容块时，对应类别不可选。
2. 查看**样子**顶部的三个选择，等待三个已测量的预览。页面不符合该类别的内容约定时，选择会停止并显示原因（提示为英文，例如 *Attribute every verbatim quotation*：请为每段原话标注出处）。系统不会替你修复或删除任何内容。
3. 选择一个通过的选择，或点**整份一起选**。你选的类别保持不变，整稿节奏只在该类别的三种结构中选择。
4. 等状态方块显示已保存，再刷新，构图保持不变。

| 类别 | 需要 | 三种结构（阅读路径） | 1440 / 1024 / 390px |
|---|---|---|---|
| 章节 | 标题；只含文字（不含图表、表格、流程图、图片、数值、代码） | 左下标题、旁侧导语 · 左侧标题与导语、右侧目录 · 窄边栏目录、右侧标题 | 2 / 2 / 1 |
| 前后对比 | 恰好两张图片，同为事实照片或同为插图，以相同宽高比显示 | 左基线、右变化后 · 文字栏加上下两图 · 基线、变化说明、变化后 | 2 / 2 / 1（三联 3 / 3 / 1） |
| 系统关系图 | 有分支或回路的关系图（单一链条属于流程） | 标题行、通栏关系图、图例行 · 左图右文 · 左图例、右关系图 | 2 / 2 / 1；侧栏与图例两种在 1024 纵排 |
| 小倍数图 | 两个及以上图表，图表类型、单位、固定数值轴（相同范围与刻度）一致；折线、面积、堆叠与热力图还需相同类别 | 面板并列、说明在下 · 标题旁为读图说明、面板在下 · 居中标题、说明与要点分列中轴两侧 | 2 / 1 / 1 |
| 引语 | 引语块，且每段引语都由引用其来源之一的出处块标注 | 居中原话 · 左转述、右原话 · 通栏原话带 | 1 / 1 / 1（居中），2 / 2 / 1 |
| 结论与下一步 | 下一步列表 | 左结论、右步骤 · 步骤排成一行 · 居中结论与请求 | 2 / 2 / 1 |

各项约定保护什么：

- **前后对比。** 内容块顺序中的第一张图片是基线。每种结构都把它放在前面（左侧、上方或第一列），并在图片上方标出“之前 · 基线”和“之后”。无需交互即可看到标签，无 JavaScript 视图和打印中同样可见。两个画框尺寸相同。两张图以不同宽高比显示时无法保存：请把两张图裁切成相同取景。页面上的对比控件必须把基线与变化后的图片配对，且不能只显示变化后的图片作为开场。
- **小倍数图。** 共用尺度由作者声明，不靠推断：每个面板都需要相同范围的固定数值轴。面板始终等大。按当前图表绘制，1440px 一页可放两个面板；1024 与 390px 时纵向排列。面板更多时，调用 `src/design/rhythm.mjs` 中的 `splitSmallMultiples(project, sceneId, perPage)` 拆页。每页保留标题与来源，面板顺序不变，文字块留在第一页。页面含交互或锁定，或某页只剩一个面板时，会拒绝拆分。Studio 暂无对应按钮。
- **引语。** 原话是引语块，以展示字体排出，并带装饰引号。标注它的出处紧接在下方。转述是段落，使用正文字体，用细线分隔，永远不会排成引语样式。说话人与机构写在出处文字中，引语块没有单独的说话人字段。

### 节奏规则

“整份一起选”现在还遵循交接包中的三条规则，仍未满足的规则会列在按钮下方的报告中：

- 同一构图最多连续两页。同一比较类别（比较、流程、前后对比、小倍数图）可以连续：一组顺序内容可以保持同一结构。
- 不出现连续三页“标题加卡片”（比较的维度卡或排成一行的下一步，且卡片不少于三张）。
- 10–15 页的文稿至少使用四种构图类别。类别来自你的内容和选择，因此这条规则只给建议：报告会列出可改用未使用类别的页面，但不会自行修改。

作者的选择优先。用“别动这页”锁定的构图即使违反规则也会保留，报告中标为“保留：作者锁定”。没有锁定却仍未满足的规则，表示没有任何已测量的候选可以避免它。

### 切换主题保留色彩模式

现在切换页面主题时，只改变主题，必要时改变构图，色彩模式保持原样。切到其他主题再切回，会得到原来的方案和相同的渲染哈希。只有页面能使用章节色彩时，才会提供紫色章节构图；色彩模式明确设为 *default* 的页面改用流式阅读。

### 出错时怎么办

- *Show both states at the same aspect ratio*（两种状态的宽高比不同）：修改其中一个裁切，使两者一致，再保存。
- *Declare the shared scale*（未声明共用尺度）：为每个图表设置相同的 `axis: {policy: "fixed", min, max}`。
- *No measured candidate fits*（没有通过测量的候选）：保留内容。改用其他类别、自行精简文字，或把小倍数图拆成更多页。

### 渲染器现在消费的 Token 角色

三套主题包声明了 S1 的 Token 角色，页面以自定义属性接收：`--numeric`（数值、图表读数、坐标刻度、表格数字）、`--reference` 与 `--missing`（参考线、缺失值标签与注释）、`--caption-gap`、`--section-gap`、`--safe-area`，以及 `--motion-distance`、`--motion-easing`、`--motion-delay`。未声明这些角色的主题包（例如 VIS-014 的三套）渲染结果与以前完全相同，因为每个消费处的回退值就是原来的字面值。动作的 `fallback`（`instant` 或 `static`）是页面自身未声明时的低动作结果。

### 中文标题在词之间换行（C12）

在 zh-CN 文档中，标题、提示语和数值标签在词典分词边界处带有 `<wbr>`，并使用 `word-break: keep-all`，因此行尾落在词与词之间（三十六种 · 几何 · 结构），而不是词内。汉字数字与量词保持在一起。`<wbr>` 没有文本内容，复制的文字、覆盖检查和所有导出器看到的仍是作者原文。页面的 `overflow-wrap: anywhere` 仍是比栏宽更长的词的最后手段。分词边界来自平台 ICU 词典（`Intl.Segmenter`）；证据记录了 ICU 版本。

### 缺字形会被检测（C13）

适配审计把页面上每个不同的字符用其计算字体画到画布上，并与同一字体的 `.notdef` 方框（未分配码位 U+0378）比较。相同即为缺字形：适配失败，Studio 门返回 `VISUAL_FIT`，构图候选报告 *Missing glyph*，质量流水线记录 `glyph` 问题，导出就绪阶段以 `FONT_GLYPH_MISSING` 拒绝。请修改文字或主题字体，绝不导出一个方框。DevTools 平台字体探针作为第二信号保留，用于引擎报告末位备用字体的情况。

### 出问题时

- *`atlas-panels` needs at least 2 chart panels* 或 *Declare the shared scale*：给每个面板相同的图表类型、单位、类别和固定坐标轴。
- *`stage-hero` … belongs to the orange-launch theme*：换主题时保留了另一个主题的专属构图；请选择新主题的构图。
- 看起来正常的页面报告 *Missing glyph*：该字符在所选字体族中被画成方框；查看适配报告中的 `glyphs` 列表确认字符和字体。
- 中文标题仍在词内断开：该词在此字号下比栏宽还长，触发了最后手段。缩短栏内文字、换一种构图，或加入作者换行。

## 样子控件、章节与锁定（S9a）

S9a 的作者动作原先在“作者控制”面板里，带范围列表和计划框。在共用外壳上，常用的几个是**样子**里的按钮；更细的动作已离开浏览器（见本节末尾）。**样子**里的每个按钮都立即生效：没有“应用／取消”。按钮下方会写明改了什么、哪些被锁定保留；顶部的**撤销**可以撤回，自动保存会保留结果。

1. 在页面条上选一页，从上往下看**样子**。（窗口窄于 1050 px 或在手机上，**编辑**会把**词**和**样子**作为面板打开。）
2. **选择。**“样子”顶部始终显示本页的三个已测量选择。点一个即采用。放不下的选择标为“放不下”。**整份一起选**会对所有页面一起选。
3. 点**多留白**。预期：本页改为所属构图类别的编辑式版式（论点先行、非对称；Editorial Fieldnotes 页面改用其封面、论点、方法、图形或结尾版式），并取宽松密度。不改主题，也不改任何文字。本页版式被锁定时按钮不可用。
4. 点**字大一点**。它默认已按下（强烈的字体对比）。预期：再按一次，整套改为均衡对比，降低展示字号档位；再按一次恢复。
5. 点**别动这页**。预期：按钮保持按下，并出现“保持本页的配色与动效。”本页的文字、数据、来源和版式被锁定，主题、交互、提示和动效也被保持。再按一次，同样的锁定解除（“放开本页的配色与动效。”）。
6. 点六种**配色**之一。预期：只改变本页主题，并按内容选取合适的构图，色彩模式不变。主题专属构图会拒绝其他主题，并说明缺少的内容块。
7. 打开**让这页会动**。预期：出现页面可以动的几种方式：**为当前页添加讲解交互**、**将本页设为“讲解 → 图解 → 探索”**、**翻页效果**（跟随主题、关或轻微）、**使用当前图表／步骤作为开场**和**打印用的静止画面**。选定其中一项后页面才会动。关闭它：页面通过移除交互、提示和翻页效果变为静止。**撤销**可恢复。
8. **图片。**有图片的页面显示**换一张图**（或**加一张图**）和 **i**。见[使用图片](#使用图片)。
9. **三个方向。**选择**少**、**中**或**多**，点**看三个方向**。选定一张卡片之前不会应用任何内容。见[三个方向](workbench.md#三个方向s9a)。
10. **样子**下方的 **↑ / ↓** 调整页面顺序。

**章节。**在页面条的缩略图上右键（或聚焦后按菜单键或 Shift F10），选择**从此页开始新章节**或**移除此章节**。预期：缩略图上出现“章节”标记。章节延续到下一个章节起点之前的一页，并沿用被它切开的章节的配置，因此渲染不会变化。章节跟随页面顺序，移动或拆分页面不会留下空隙。

**样子按钮不做什么。**多留白、字大一点和配色都保留原文、数据、来源、裁切和其他页面。锁定从不被覆盖：按钮下方的说明会列出每一项被锁定保留的内容。

**页面折叠内容。**更细的作者动作移走的文字显示在构图之后，标为“更多细节 · n 项”。读者可在页面上展开，无需 JavaScript。PowerPoint 将其放入幻灯片备注并为每项内容给出回执，PDF 放在备注页。

**四个层级。**偏好按“对象 → 页面 → 章节 → 整套”由具体到一般生效：页面配置优先于章节配置，章节配置优先于整套配置。播放器同样遵循这一顺序：动效关闭的章节或页面不播放动效，整套的“关”仍然处处优先。**样子**里的按钮作用于当前页；其他范围通过 API 使用。

**锁定。**浏览器里只有一个锁：**别动这页**；逐项锁定的复选框已删除。锁定状态在**更多 → 给开发者**里以只读方式显示。API 仍可分别锁定“文字”“数据”“来源”“构图”：文字锁定对象的书写内容，数据锁定数据集（数值、单位、定义、缺失原因、事件与区间），来源锁定来源记录，构图锁定页面版式。第一次使用数据或来源锁定时会运行显式迁移 `separateLocks()` 并说明；旧（合并模式）文稿中它会复制隐含的锁定，不会释放任何锁定。每个锁定都会在换主题、保存来源更新和**更多 → 之前的版本 → 恢复为新副本**后保留。

**已移到 API。**下列 S9a 动作在浏览器里不再有控件，`POST /api/visual/author-action` 仍会执行，计划、范围说明和锁定检查不变：减少文字、给图表更多空间（含把多于两个图表面板的页面拆开）、更安静、保留此版式、替换视觉、分项锁定与解锁、开始与移除章节、应用配置。图片审阅（工作台文稿的截图、审阅、报告和审阅后导出）与页面规划（`POST /api/visual/page-plan` 和 `/page-plan/apply`）也一样；见[工作台手册](workbench.md#图片审阅与页面规划仅-api)。`tests/browser_author_controls.mjs` 与 `tests/browser_workbench.mjs` 会逐一调用它们。

### 页面用途与入口（CINE-003）

**样子**按钮下方有两个下拉框，说明当前页是做什么的、视线从哪里进入。两者初始都是“自动”：此时用途与入口按内容和构图推断，计划里不写入任何字段。

1. 选择一个**页面用途**（讲解、展示产品、展示细节、比较、证据、总览、章节）。预期：计划框显示“用途 …，入口 …”；当该页所属类别对这一用途有偏好版式时（图片页选“展示产品”→ 标题 → 左文右图），构图随之改变，并写明新旧版式。构图锁定会保留版式并说明。文字、数据与来源不变。**撤销**可撤回。
2. 选择一个**入口**（左侧、居中、构图指向之处）。预期：入口为左侧的短文字页从页面顶部开始排布，而不再居中；居中入口保持开阔的居中留白。该页的 section 带有 `data-purpose` 与 `data-entry`；保持“自动”的页面不带这两个属性，渲染与之前相同。
3. 在**页面用途**中选回“自动”。预期：声明被清除，页面重新按推断处理；构图保持原样。
4. 点**给视觉更多空间**（有图片或图解的页面可用）。预期：本页改为在 1440 px 下把主图绘制得最大的版式（标题 → 左文右图；Luminous Stage 主题用其舞台主体版式），图解则改为宽幅系统关系图；图片的角色被声明为“主体”（图解为“机制图”；第二张图片变为“辅助”，按 260 px 绘制）；第一段之后的辅助段落与列表移入**更多细节**（第一段留在页面上作为说明，与“减少文字”一致）。计划框写明每项改动。构图锁定保留版式；`media` 锁定保留角色。对应的 API 动作是 `visual-space`（层级 `page` 与 `object`：对象层级把所选图片设为主体）。

对应的 API 动作是 `set-intent`（`POST /api/visual/author-action`，层级 `page`，选项 `{purpose, entry}`；`purpose: null` 为清除）。本批次里紧凑引用没有浏览器控件：通过 API 或项目 JSON 在页面上设置 `references: {mode: "compact"}`（见[迁移](migration.md#来源呈现页面意图与媒体角色cine-批次-1)），来源条、编号与参考面板随即出现在页面和两种导出中。`intent` 锁定（`sceneLocks[].fields`）会保留声明；焦点块是引用的页面会拒绝声明意图。

### 带走

1. 点顶部的**带走**。预期：对话框“把你的故事带走。”列出**放映**、**HTML**、**PowerPoint** 和 **PDF**。页面测量完成之前，放映和 HTML 是灰色。

7. **项目 JSON**（完整备份）和**最近一次已接受的 HTML**在**更多 → 备份与还原**里，不在此对话框。

## 讲解 → 图解 → 探索页面（S9b）

含有标题、段落或提示框以及一张图的页面，可以变为“讲解 → 图解 → 探索”页面（蓝图 A）。读者一侧的说明见[交互](interactions.md#讲解--图解--探索蓝图-as9b)，证据见 [S9b 审阅（英文）](../evidence/s9b-blueprint-a/review.md)。

1. 选中该页，打开**样子**，把**让这页会动**打开。
2. 点击**将本页设为“讲解 → 图解 → 探索”**。预期：消息说明本页已变为“讲解 → 图解 → 探索”；预览从“讲解”打开本页并显示阶段标签；**打印用的静止画面**列出“讲解”“图解 · 整体”和“探索 · （第一部分）”；提示说明在选定静止画面之前，PowerPoint 与 PDF 导出会拒绝本页。标题是问题，第一个段落或提示框是简短答案，每个图节点按节点顺序成为一个部分。内容块不变。
3. 在**词**的**分步讲解**下修改文字：“整体对象 · 名称”（初始为用箭头连接的各部分标题）、“整体对象 · 说明”，以及每个部分的标题和说明（初始为节点标签和注释）。图中节点已有的说明会保留。
4. 选择静止画面：**图解**或某个**探索**状态。预期：提示显示“静态状态：…”，并说明不使用 JavaScript 的读者以及 PowerPoint 与 PDF 都会得到完整对象、每个部分及其说明，而播放器仍从“讲解”打开。
5. 等状态方块显示已保存、页面测量完成（**带走 → HTML** 不再是灰色），然后导出。测量覆盖开场和本页的每个关键状态。**PowerPoint** 与 **PDF**（Studio 以 `--capture-browser` 启动时）导出完整说明；消息会列出导出阶段。

**撤销**和**重做**会整体撤回或恢复这次操作，自动保存即保留，**更多 → 之前的版本**可将其恢复为副本。锁定：

- 按下**别动这页**时（它同时保持本页的交互、提示和动效），按钮不可用。
- 图被锁定时会被拒绝：*Unlock the diagram first.* 再按一次**别动这页**即可放开本页。
- 页面的提示与动效被锁定时，静止画面保持不变；要改选，请先解锁。

### 出问题时

- *This page needs exactly one diagram on the page*：添加一张图，或把第二张图移到其他页。放在“更多细节”里的图不计入。
- *Add a heading (the question) and a paragraph or callout (the short answer)*：先添加，再点击一次。
- *An Explain → Diagram → Explore page has one explanation sequence*：先把本页的其他交互移到别的页面。
- *This diagram's steps explain relationships*：蓝图的部分必须是节点；先在**更多 → 给开发者 → 数据编辑 → 作者交互、提示顺序与动效 · JSON** 中移除该分步交互，再点击一次。
- 导出时出现 *Page …: Choose the static state…* 或 *The Explain stage does not show the object…*：选择“图解”或某个探索状态（第 4 步），保存后再导出。

## 图片槽位中的主体标注（CINE 批次 2）

图片槽位通过原有的槽位路径（`POST /api/visual/image-slot`，动作 `configure`，与**应用**按钮发送的请求体相同）接受批次 2 的简报字段；本批次工作室里没有对应的绘制控件（CINE-011）。在槽位的 `brief` 中设置它们（[迁移](migration.md#主体标注字号角色与软性特征cine-批次-2)）：

1. 加入 `subjectBounds`（画出的主体），需要裁切保留更多时再加 `protectedRegions` 与 `contextRegion`。预期：**给视觉更多空间**与各裁切按钮让每个保护区留在裁切内且不超出场景区；下限装不下的裁切被禁用，API 以 `PROTECTED_REGION` 拒绝（`contain` 仍可用）。测得的主体占比报告 `annotated: true`。
2. 加入 `visibleCaption`。预期：页面在图片下方显示它；替代文本仍留在图片上以及 PowerPoint 的图片描述里。
3. 在细节页上，给细节的简报加入 `detailLocator: {blockId, region}`，指向本页显示整体的图片。预期：定位图在该矩形处画出一个框。
4. 标记证据截图（`role: "product-screenshot"`、`factual: true` 并指定来源）。预期：槽位切换为“包含整图”；裁切按钮以 `PROTECTED_REGION` 拒绝。

### 出问题时

- `SAFE_REGION`：场景区必须包含安全区、主体与每个保护区；放大场景区或移动这些区域。
- `IMAGE_SLOT … A detail locator names another image of this page`：定位图必须是绑定到同一页的另一张图片块。
- `PROTECTED_REGION`：选择“包含整图”，或明确放宽保护区；任何裁切都不会切过保护区。
