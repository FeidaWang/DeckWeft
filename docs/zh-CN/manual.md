# 简单手册：像整理一本小书一样做幻灯片

[English](../en/manual.md) · [首页](../../README.zh-CN.md)

当前本地构建的[私密演示与排练指南](presenting.md)介绍独立观众窗口、自动跟随提词器、外观与动效设置。视觉导出默认不含私密讲者备注；需要讲者副本时显式勾选包含备注。项目 JSON 仍是完整私密备份。工作区的“比较布局”可收起候选区。

## 左边是书页，中间是舞台，右边是工具箱

左边选择文稿和页面，也可以添加、导入或打开历史。中间是观众会看到的页面，下方有四种排法。右边修改内容、设计和来源。分数只是规则适配度，不是事实正确率，也不是 AI 的自信程度。

## 先写一份小大纲

点“新建”，每页先写标题，再写说明。单独一行 `---` 表示翻到下一页，`-` 开头的一行表示要点。例如：

```markdown
# 一个小改进
先说最重要的结论。
---
# 怎么做
- 写清故事
- 比较排版
- 检查导出
```

这个按钮整理你的文字，不会自行上网、调用模型或补出研究依据。数字栏每行写 `4 | 排版选择`，竖线左侧是数字，右侧是标签；它们是可编辑卡片，不是原生数据图表。来源网址也不等于事实已经核实。

## 给文字足够的空间

可以换主题和 16:9、4:3、1:1、9:16 比例。浏览器像拿着尺子一样，用本机可用字体测量整段文字，再给出四个布局。等到“浏览器已实测 · 可以导出”后，视觉导出会使用同一份测量结果，不再另算一套。

文字放不下时，不会偷偷删掉，也不会无限缩小。换布局、手动缩短文字，或拆成两页。修改后旧测量就作废；测量中、字段错误或请求失败时，旧预览会变暗，布局选择和视觉导出暂时不可用。修复字段或网络恢复后继续编辑即可重新测量。

只探测预先声明的少数字体，不枚举整台电脑的字体，不向云端上传文字，不下载或打包字体。隐私设置可能限制探测。PowerPoint、Figma、AE 仍可能替换字体，因此导出后要在目标软件中检查。**没有浏览器参与的 CLI 导出仍为离线估算，不冒充实测。**

## 保存像按一次“装订”

点“保存”或按 `⌘S` / `Ctrl+S`，才会写入磁盘。保存期间继续输入的内容仍会显示为“未保存”，不会被较早的保存结果覆盖。普通文字输入框里的撤销由输入框处理；在输入框外，`⌘Z` / `Ctrl+Z` 撤销文稿修改。连续输入会合并成一组，关闭页面后不会保留本地撤销栈。

另一窗口先保存时，当前保存会被拒绝，但你的草稿仍留着，并弹出“另存为独立副本”。预期结果：新文稿保存你的修改并在当前窗口打开，较新版本不变。也可以选“继续编辑”，先导出项目 JSON 备份，再重新打开最新版，决定要重做哪些修改。系统不自动合并两份修改。

页面开着时本地工作室重新启动过，下一次保存（或预览）会提示“本地工作室已重新启动。”选“重新连接并保留修改”。预期结果：页面不刷新，修改仍在，保存照常经过上面的覆盖检查。选“暂不”则修改保持未保存，再点保存即可重新连接。

## 历史恢复像翻相册，但不会撕掉现在这一页

点左侧“历史版本”，选择一个保存版本，查看只读预览。可以翻看其中各页；“更早的版本”继续加载历史。

点“恢复为新副本”，系统会另存一份文稿，分配新 id，从版本 1 开始。**原文稿不变，当前未保存草稿也不变。** 点“打开恢复的副本”才会切换；有未保存内容时，可选“保存并继续”“放弃修改并继续”或“留在这里”。同一次恢复请求重试不会反复生成重复副本。

第一次保存还没有历史。修改后再保存，上一版就会出现。损坏版本会标记为需要修复，不会自动删除；浏览后文件被改动，会要求刷新再恢复。历史保存在 `~/.deckweft/history/项目id/`，**暂时没有自动清理和保留数量上限**，请自行备份并留意磁盘空间。没有保存过的输入不属于磁盘历史，不能靠这个界面找回。

## 导出选哪一种盒子？

| 格式 | 简单理解 | 说明 |
| --- | --- | --- |
| 项目 JSON | 整份配方 | 保存完整支持的数据；临时无效的字段也能备份，但重新导入前要修好 |
| PowerPoint | 演示文件 | 原生文字和基本形状，可编辑；不包含原生图表或复杂动画 |
| HTML | 离线小书 | 用浏览器查看 |
| SVG | 当前这一页 | 矢量文字和形状，不内嵌字体 |
| Figma / AE JSON | 给导入器的说明书 | 不是已经创建好的 `.fig` 或 `.aep`；仍需在实际应用中执行和检查 |

## 键盘和小窗口

输入框外按 `1`–`4` 选择当前四个布局。演示时用方向键或 Page Up/Down 翻页，Home/End 到首尾，Escape 退出。小窗口点“页面”或“编辑”打开抽屉；Escape 关闭并返回触发按钮，Tab/Shift+Tab 在弹窗内循环。输入法组词期间，应用快捷键不会抢走操作。测试目前使用合成输入法事件，真实 macOS 输入法和屏幕阅读器仍需人工验收。

“中文 / English”只切换界面；“文稿语言 / 字体偏好”选择语言标记和字体候选，都不会翻译现有文字。

## 常见问题

找不到 node：安装 Node.js 22 或更高版本，重新打开终端。端口占用：使用已有窗口，或启动时加 `--port 4180`。提示正在别处保存：稍后重试；崩溃后先停掉所有 DeckWeft 进程，备份后仅清理确认失效的 `.json.lock` 文件，不要删除活跃锁来强行写入。

如果历史快照与同版本内容冲突，系统拒绝覆盖，请备份整个文稿库后排查文件，不要为了通过而删掉未知历史。字体不同：自行安装合适授权的字体，或在演示软件里更换后逐页检查。工作台不会暗中上传；你选用的模型宿主、浏览器扩展、备份软件和云端设计应用仍有各自的隐私规则。本地保存不等于加密。
