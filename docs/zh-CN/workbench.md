## 先看作品

打开已保存的文稿，首先显示作品画布。下方缩略图使用同一份派生页面，显示真实图片、图表与构图。点击缩略图、使用上一页／下一页，或在缩略图中使用方向键翻页。“放大页面”使用可用宽度阅读；“适合工作区”返回概览尺寸。

“创作”提供原文、来源与设计偏好；“编辑本页”提供当前页的内容、设计与范围修订。两栏不会同时挤占画布。“回到作品”收起侧栏，保留未应用及未保存的编辑。“文件与历史”收纳撤销、重做、历史和项目备份。“创作 → 导入与样例”提供导入和样例入口。

本地模式只排版所提供的原文，用 `---` 分页；一页原文保持一页。它不会研究主题、改写文字或重复内容凑页数。需要根据需求起草时，明确选择 Codex；仅在此模式显示对应的操作许可。设计偏好有独立可见的单页／项目范围，不会沿用隐藏的修订范围。

“探索构图与整篇节奏”提供构图比较；“审阅与导出”提供截图许可、实际图片和作者判断。缩略图不代表通过导出审阅。项目和恢复下载仍包含私人存档材料；面向观众的 HTML 由页面渲染，不复制编辑器。

1. 运行 `node bin/deckweft.mjs studio --open`，从经典库进入 Visual Studio，或打开所打印本地地址的 `/visual`。
2. 输入要讲述的故事，可选本地 `.txt`／`.md` 来源，最多 12,000 字符。在“创作”栏点击“排版所提供的原文”，或选择 Codex 后点击“根据需求起草”，或用“使用／继续所选文稿”处理已保存的视觉项目。先保存编辑器修改。本地模式只排列原文，不调用模型、不改写语气；这里尚未实现任意 PDF／Office 文档解析。
3. 按需展开“语言与设计偏好”。界面、提示词、输出语言独立保存，内容语气与视觉风格另有字段。输出语言控制起草与格式，不会悄悄翻译受保护原文。“更新偏好”记录作者意图；所有更新仍需显式操作，每份变更后的 HTML 都必须重新审阅。
4. 需要 Codex 起草／审阅时，选择 Codex CLI 并允许此次操作。它使用已有宿主配置，可能消耗额度；不会登录、替换模型／提供方或推断计费。Claude 继续暂缓。
5. 点击“观看预览”打开带演示导航的观众页面，不包含编辑器控件。预览不等于已验收导出。
6. 选择页面，输入修订，如 `Use evidence-top; keep every word and other page`。Codex 可为既有构图／精确数据图表契约理解普通表达；本地模式仅支持具名构图和有限图表语法。图表未绑定数据时，需明确选择已有精确数据集，缺失数据会停止操作。`Use dark-data` 会在本地应用类型化范围偏好。更广泛的改写请使用已有高级编辑器，不把未支持的文字要求当成已执行。
7. 应用偏好前选择“仅选定页”或“整个项目”。单页偏好保存在该页，不覆盖项目默认值；色彩／图片比重采用同一派生渲染器读取的类型化页面配置。锁定主题、构图仍受保护。“保留本页图片及裁切”新增作者图片锁；生成、主题变更和来源同步都不会自动解锁。

## 六个问题与三个方向（S9a）

**创作**栏先问六个问题：**主题**（文本框）、**受众**、**风格**、**详细程度**、**动效**和**输出**。语言、语气、色彩、图片比重与更新偏好放在**更多选项**中。DeckWeft 先用三种方式绘制同一内容，再生成整套演示。三个预览在图形、字体、媒体与动效上不同，事实完全相同。

1. 打开**创作**，粘贴原文（页与页之间用 `---`）或需求，并回答六个问题。**风格**可选“根据内容建议”或六套主题之一。**详细程度**决定 DeckWeft 期待哪些材料：
   - 简要：问题、证据、行动；
   - 标准：再加背景与局限；
   - 详细：全部六种论证单元。
2. 选择**内容**：“上方文字”（新建文稿）或“当前打开的文稿”（为已打开的文稿换设计）。点击**显示三个方向**。
3. 画布区出现**三个方向**。每张卡片包括：
   - 已测量的预览和样例页按钮；
   - 此方向改变什么：*图形*（底色、强调色、各样例页的构图、多少页更换构图）、*字体*（标题、正文、数字字体与对比）、*媒体*、*动效*（会播放什么，或开启动效后会播放什么）和*输出*（在 PowerPoint 或 PDF 中有多少元素为 L1、L2 或 L3）；
   - 排版结果，例如“✓ 1440 px 下全部 5 页通过”。

   卡片上方显示共同的事实哈希。高于 900 px 候选预算的页面会列出，但不阻止选择；其他排版失败会禁用**使用此方向**。
4. 阅读卡片上方的**论证单元**。缺少的单元或缺乏支持的论点会变成提问，例如“第 3 页的论点由哪些数据、来源或引语支持？DeckWeft 不会编造。”不会为凑页数添加任何内容。
5. 点击**使用此方向**。
   - 选择“上方文字”时，工作台用该方向生成整套演示。服务器对同一份规划内容重新应用该方向，所以结果就是预览所示的设计。
   - 选择“当前打开的文稿”时，该方向经正常编辑路径应用到每一页，**撤销**可恢复之前的设计。你锁定了主题或构图的页面保持不变，卡片会写明保留了几页。

如果没有出现方向，提示会说明原因：主题为空、字段未知，或文稿有未保存的修改（请先保存）。

**修订所选范围**与**应用所选范围偏好**现在会在运行前显示范围说明，例如“范围：第 3 页。可能修改第 3 页的 composition、chart data binding、theme；其他页面不变。事实、数值、单位与来源不会被改写。”说明随当前页与范围选项更新，并列出该范围内的文字、数据、来源或构图锁定。

### 按论证规划页数

打开**编辑页面 → 作者控制 → 按论证规划页数**。

1. 选择详细程度，可选填写目标页数，点击**规划页数**。
2. 预期看到一张表：每页的论证单元和判定依据（*label*、*structure*、*keyword* 或 *position*，以及起决定作用的词）、文字长度与所需页数。
3. 材料不足之处会出现提问。常见的有：缺少的单元、没有来源的论点，或“材料支持 5 页，目标为 9 页……DeckWeft 不会填充页数。”
4. **标记待补证据的页面**会标记缺乏支持的证据页，页面列表中出现“待补证据”标记。最终导出（HTML、PowerPoint、PDF 以及工作台的审阅后导出）会以 `EVIDENCE_REQUIRED` 拒绝这些页面；预览仍可使用。要清除标记，请补充证据并将页面设为 sourced，或设为 illustrative。
5. **拆分过长页面**把整段文字和列表移到续页，续页重复标题，不改写任何文字。撤销可恢复。

### 将设计保存为可复用的配置

配置只保存主题、配置选择（色彩、对比、密度、动效、图片比重）、每类页面所用的构图，以及实际绘制的字体与动效 token。它没有可存放文字、数据、来源、图片或品牌的字段。

1. 保存文稿。在**作者控制 → 设计配置**中输入名称。
2. 如果文稿已在本工作台通过图片审阅，配置以该审阅作为接受依据；否则请勾选**我接受此设计**。
3. 点击**将此设计保存为配置**。预期提示写明主题和构图选择的数量。被拒绝时会给出原因：
   - `PROFILE_UNSAVED`：请先保存；
   - `PROFILE_NOT_ACCEPTED`：请通过审阅或确认接受。
4. 重新载入 Studio 并打开另一份文稿，配置仍在列表中。在整套、章节或页面范围选择**应用配置**，阅读说明的效果后再应用。
5. **导出配置**下载 JSON；**导入配置**将其加回，若 id 已存在则作为副本导入。配置保存在 `<library>/visual/profiles/`。如果主题的绘制方式与保存时不同，应用时会列出变化的 token。

## 实际截图与审阅

运行时没有外部依赖。截图必须显式配置并允许。用 `/Applications` 之外的隔离 Chromium 可执行文件启动：

```bash
node bin/deckweft.mjs studio --capture-browser /absolute/isolated/chromium
```

不会自动使用个人浏览器／配置，也不修改或重新签名浏览器。每次允许的操作使用临时配置目录、loopback 派生产物，等待字体／图片和当前排版后，在 1440／390px 截取实际 PNG。Node 内置 WebSocket 控制隔离进程，PNG 哈希绑定既有质量回执。除完整故事外，还捕获图片／图表／流程图原尺寸视图，并保留既有 20 张图像上限。交互故事仍需真实动作轨迹；缺失时阻止通过，不编造证据。密集滚动组件和穷尽交互状态仍属更广验收范围。

1. 勾选“允许此次操作使用隔离本地浏览器截图”，点击“截图并审阅”。未配置截图能力时保留可恢复预览，禁止最终 HTML 导出。
2. Codex 模式会实际附加截图，所有必需图像都需有哈希匹配的判断。质量检查、来源身份、范围、作者锁、累计两轮修复预算继续生效。
3. 本地模式展开“检查实际图片／作者审阅”，逐张打开原尺寸链接，检查完整故事和组件，写下可见判断及最弱页面，选择通过／失败并明确确认已实际查看。文件加载不代表看过，自动排版检查不能代替图片判断。
4. 只有当前回执通过才能“导出已审阅 HTML”。原文、渲染器、截图变化，审阅失败或项目有更新修订都会阻止导出。旧的预览测量导出接口也不能绕过，即使客户端删除工作台元数据。

## 继续与恢复

1. 重新打开已保存的项目，选择“使用／继续所选文稿”，或在同一浏览器会话点击“继续上次任务”。任务检查点和偏好保存在本地视觉库，独立于观众 HTML。
2. 其他编辑器保存较新内容时会报告冲突，不覆盖较新项目。明确点击“同步已保存来源”，然后重新截图、审阅。同步保留作者锁、最后通过的产物及累计修复预算。
3. “取消操作”停止宿主／截图工作。“恢复中断任务”只能在原服务器结束后使用，不抢占活跃操作。重启后不会自动重试模型调用。
4. “恢复检查点”包含原始来源及私有归档材料，应保持私有。失败后“最后通过的 HTML”明确下载先前验收产物，不把当前失败候选标为通过。

观众 HTML 可以保留公开引用，不渲染归档的私有讲稿、检查点、提示词或宿主回执。项目／检查点导出保留恢复所需归档内容，不应作为观众文档分发。
