# 图表、图解、代码与注释

[English](../en/components.md) · [Visual Studio](visual-studio.md) · [证据](../evidence/vis-008/review.md)

1. 使用 Node 22 或更新版本运行 `npm run studio:components`，打开终端打印的本机 `/visual` 地址。独立本地库包含中英文各一份 14 页故事，保留原有四页内容并增加十页组件。在文稿库中选择语言版本；其他库可点击“组件样例”。
2. 选中组件页面，在“内容”中编辑。图表数据使用 JSON 数字，以 `null` 明确表示缺失；单独编辑 `chartType`、`axis` 和散点可选的 `xAxis`。图解 JSON 可编辑节点、定向连线、标签和节点说明。代码具有原文输入框，以及 `language`、从 1 开始的 `emphasizedLines` 和 `sourceAnchor`（`sourceId` 与原始来源位置）元数据。
3. 等待字体、图片和排版测量通过。预览、标签、图例和完整数据表使用同一份文稿。展开“查看完整数据”或“关系与节点说明”，也可用键盘操作。静态内容不依赖动画或 JavaScript；窄屏的图表、大图解和原文代码可在组件内部横向滚动。
4. 在设计中比较构图，查看候选，选择通过的候选或整稿节奏。没有可行候选时，需要调整布局或由作者明确修改内容。测量不会截断数据或代码以求通过。
5. 保存、重新打开，或导出已测量 HTML 与项目 JSON。内容保持语义化可编辑，HTML 使用 DOM／SVG、转义代码和精确数据表。v3 的原生 PPTX／Figma／AE 编译器仍不可用，会明确拒绝。组件能力回执不代表真实宿主已验收。

## 数据规则

`chartType` 支持 `line`（折线）、`area`（面积）、`ranked-bar`（排序条形）、`stacked`（堆叠比较）、`scatter`（散点）和 `heatmap`（热力矩阵）。旧 v3 图表省略类型时仍为含零坐标轴的折线图。v1／v2 保持原有路径，迁移仍须明确执行。

每个系列为每个类别提供一个有限数字或 `null`。不会转换数字字符串、插值、把缺失补零、自动归一化百分比或修改源顺序。零是真实观测；折线和面积遇缺失会断开。堆叠中任一成员缺失时整组不绘制，已有部分数据仍完整保留在表中；正负值分别累加。排序条形只接受单系列，在派生视图中排序；相同值保持顺序，缺失排在最后，数据表保持原顺序。

散点需要系列的数字／null `xValues` 和数据集 `xUnit`；两个坐标均存在才绘制。数据表和标记标签保留原数值，坐标刻度可为节省空间舍入，不替代原始数据。过长标签可能测量失败；可换构图或由作者明确修改标签，并保留来源引用。

`axis.policy` 为 `zero`（默认含零）、`extent`（数据范围）或 `fixed`（固定范围）。固定坐标轴必须有递增的 `min`／`max`，不能隐藏原值或堆叠正负总量。面积、条形与堆叠须包含零。全缺失时显示 0～1 坐标轴，常量数据在派生坐标轴中留出边距，均不改写观测值。热力图按显示的范围计算颜色强度；正负颜色、原数值和缺失虚线框共同表达含义。系列名称是行标签，图例说明正负、零与缺失。

时间类别须指定 `categoryKind: "datetime"`、IANA `timeZone` 和严格递增、包含 `Z` 或数字偏移的 ISO 时间点。原始时间保留在表中，显示标签使用指定时区，折线／面积按真实时间间隔定位。无效日期、含糊的本地时间和无效时区会被拒绝。示例跨越墨尔本十月夏令时切换；普通类别不会被推断时区。

## 稳定关系与原文代码

图解类型为 `relationship`、`sequence` 和 `process`。只绘制给定的 `from` → `to`，不根据邻接或节点顺序增加关系；时序消息按给定边顺序排列。可选边 `id` 与节点 `id` 共用唯一命名空间。自动布线是有界实现，不是最优图布局引擎；复杂图需查看实际画面，关系清单提供精确的静态文字表示。

注释用 `target.blockId`，可选图解 `objectId`、图表类别的稳定 `categoryIds` 条目作为 `objectId`（可加 `seriesId`），或代码 `line`。类别身份必须与类别一一对应。注释和目标必须同页；重排页面、排序条形、选择构图均保留身份。删除目标会失败，不会按数组位置重新绑定。代码行引用是作者指定行号；插入代码行后，应明确同步修改行引用及强调行。

代码只作为转义文本，不会执行。制表符、CRLF／LF、尾空格、结尾换行和来源锚点在 HTML／JSON 中保留。逐行强调不插入额外文字。原文输入框保留统一的 LF 或 CRLF；混合换行须使用转义 JSON 编辑，避免文本框自动规范化。来源 URL 只提供手动打开链接，程序不自动抓取。

JSON 修改失败时，按提示修复字段；离开前导出“项目 JSON”可保留未应用草稿。保存时保护锁定内容及共享数据集。修订冲突时保留备份，重新打开当前文稿；可在历史中将旧版本恢复为独立副本。没有新增运行依赖、远程服务或自动图片请求。交互动画留待 VIS-009。
