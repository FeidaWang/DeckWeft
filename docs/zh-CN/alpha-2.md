# alpha.2：真实测量文字，安全找回旧版

[English](../en/alpha-2.md) · [手册](manual.md) · [验证](verification.md)

版本为 **0.1.0-alpha.2**。项目 Schema 仍为 1，alpha.1 文稿无需迁移。升级前备份文稿库，停止旧服务，再从新源码启动；安装过的技能自带运行文件，因此也需按原安装路线更新。不要删除 `~/.deckweft` 来升级。

本轮先尝试 DW-020：真实宿主程序不存在、没有可用登录环境，安装源 DNS 也不可用，所以保持阻塞。增加了可在真实机器重跑的验收工具，不把模拟结果当作通过。

DW-130 已实现浏览器整段排字、有限的本地字体探测、字素安全换行以及同一份测量的预览/导出。过期或内容不匹配的测量不能再用于导出。独立 CLI 仍标为估算，目标软件替换字体时仍要检查。

DW-120 已修复输入法事件、撤销分组、弹窗焦点、快速重开弹窗丢失处理器、保存期间继续输入、多窗口竞争和旧预览覆盖。真实输入法、200% 浏览器缩放、屏幕阅读器及其他浏览器仍未完整验收。

DW-110 的历史界面已实现：分页列表、只读实测预览、按所查看哈希恢复、重试幂等、新副本和来源记录。恢复不改原文稿，不替换当前未保存草稿。保留策略、自动清理和归档仍待做。

没有新增框架、数据库、收费模型依赖或云上传；没有打包字体，没有声称本轮修改了云端 Figma 或运行了 AE。源码、插件版本一致，英文手册和中文手册同步更新。实际测试数字、日志和环境限制见验证报告。
