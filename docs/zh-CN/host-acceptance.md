## 先做不调用模型的检查

在源码目录运行：

```bash
node bin/deckweft.mjs host-check --target both --out host-evidence-preflight
```

每次使用空输出目录；即使中断任务尚未写出报告，也不会覆盖已有任务文件。程序复制独立插件、计算哈希、测试 CLI，并调用真实宿主的版本、帮助及可用的 Claude 校验器。预检查使用临时主目录，移除已知鉴权环境变量，不自动安装宿主或修改全局市场。退出码 **2** 表示完整验收尚未通过，不代表报告没有写出。

## 再明确允许一个真实小任务

先通过官方应用安装并登录宿主，不要把密钥放进仓库。然后运行：

```bash
node bin/deckweft.mjs host-check --target both --live --out host-evidence-live
```

`--live` 才会使用已有登录，可能消耗套餐或 API 用量。任务是虚构纸飞机俱乐部的三页英文文稿，输出 JSON、HTML、PPTX，检查语言和随机标记，使用打包后的 CLI 独立重导出并逐字节对比。提示不提供备用技能路径，宿主必须发现已安装技能。模型任务不使用浏览器或无关连接器，由审阅者单独检查产物。可用 `--timeout-ms 180000` 调整超时；范围为 1000–600000 毫秒，默认为 120000，不会放宽权限。不绕过权限；需要批准、参数不支持或超过时间限制时，会如实停止并记录。临时工作目录保留供检查，终端会打印位置；检查后只删除那个确切目录。

Claude 走本次会话的 `--plugin-dir`。自动化 Codex 走**独立项目技能**，不等于原生桌面插件已经通过。原生市场激活、实际调用和视觉检查仍要单独完成。两种安装路线不要混为一谈。

## 最后亲眼检查

打开 `report.json`、脱敏命令输出和三页结果，确认宿主确实调用了插件内运行文件，而不是临时另写导出器。记录版本、调用方式、权限提示、文件哈希和实际渲染结果。只有进程成功或生成文件时，仍需人工审阅；脚本故意不会自动把完整发布关卡标为通过。
