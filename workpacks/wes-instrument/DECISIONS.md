# Architecture decisions
- **ADR-001 / extend, do not rebuild:** retain DeckWeft ESM, existing shell and shared scene/export pipeline. Resolve v1/v3 contracts in Phase 00 before adding fields.
- **ADR-002 / evidence before polish:** source identity and editable output are P0; instrument effects follow a working vertical slice.
- **ADR-003 / raw vs derived:** movie/community colours and application accessibility tokens are separate data, versioned independently.
- **ADR-004 / no magic universal reading path:** select layouts by task and measured fit; validate comprehension, not just gaze or liking.
- **ADR-005 / instrument is optional:** dial selection has native keyboard/touch alternatives. Sound is opt-in and never necessary.
- **ADR-006 / local core:** no new paid model dependency. Explicit handoffs from existing agents are data, not permission to call APIs.
- **ADR-007 / opaque vendor code:** unavailable internal Slides code is not a dependency. Adapter capability checks replace guessed APIs.
- **ADR-008 / honest scope:** missing film-frame, product-catalogue and research coverage is a tracked backlog, not fabricated completion.
- **ADR-009 / evidence-based release:** separate structural export tests, visual inspections and real Office/host tests.
